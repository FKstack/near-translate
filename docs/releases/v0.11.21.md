# 近译 v0.11.21

DeepL 受限时保留已经完成的译文，等待后自动继续未完成内容。本版首次受限的默认等待为 **30 秒**，无需填写 DeepL API Key。

- 修复篡改猴跨文章翻译时启动记录丢失及共享冷却被较短期限覆盖的问题，减少停止后重试和连续文章造成的请求堆积。
- 冷却结束后先用一个真实的未完成批次恢复连接，成功后再恢复并发；中短文适当减轻并发负载，大文章保留快速队列。
- 自动恢复保留译文与原始进度，停止、退出或切换设置会取消等待。连续受限仍按 30/60/120 秒等逐步退避，自动恢复最多三次、窗口十五分钟；服务端指定的更长期限不会被截短。
- Chrome / Edge 扩展、PDF 阅读和文档转换继续保留；模型翻译继续使用原来的流式显示。设置与已保存的 API Key 继续使用。

从原 GitHub 或 Greasy Fork 渠道更新，交由篡改猴确认安装后刷新已经打开的文章。已安装本地 0.11.20 的用户同样可升级本版；无需重填配置。脚本的每日更新检查和 Greasy Fork 平台拉取都可能延迟，公开同步完成后也可从原渠道手动更新。

## 验证范围与限制

按用户要求，本次不额外进行真实 DeepL 测速。0.11.19 的历史验证为隔离浏览器连续二十篇、实际 Edge 连续十篇完整完成，并记录了真实 HTTP429 后的等待与自动恢复；实际 Edge 两篇 Go 长文为 14.6674/14.9809 秒。这些样本使用当时的六十秒基础冷却，不能当作本版三十秒策略已经实网验证，也不构成固定速度或上游可用性保证。

发布工作流继续执行仓库、文档、类型、单元测试、模块边界、Chrome/Edge 构建及两种脚本的浏览器检查，结果以本次 PR 和 Actions 为准。免费上游仍可能限流；超出恢复预算时保留译文，等待用户主动继续。完整历史与失败记录见 [DeepL 可靠性报告](../reports/DEEPL_RELIABILITY_2026-10-26.md)。
