BEFORE YOU START

你可能想问。

还有问题？
到 GitHub 聊聊 ↗

近译免费吗？

近译以 MIT 许可证开源，没有近译会员订阅。本地阅读与文档工具无需模型 Key。DeepL 免费服务是实验性接入，可能限流；自带模型 API 的费用由所选服务收取。

一定要配置 API Key 才能用吗？

本地阅读不需要 Key。普通网页与句段翻译可以选择 DeepL 免费服务；英语语境词典和长句拆解需要模型模式。可以先阅读，等有需要再配置。

扩展版和篡改猴版，选哪个？

需要 PDF 阅读和文档工具，选 Chrome / Edge 扩展。已经使用 Tampermonkey、主要阅读网页，可以选篡改猴版。两版设置独立，同一网站请只启用一种。

可以直接翻译整本 PDF 吗？

目前 PDF 翻译针对选中的文字，不是整本文档一键翻译。扫描版 PDF 需要先通过 OCR 获得文字层；网页正文则支持段落双语翻译。

我的文章和 API Key 会发到哪里？

点击翻译后，相应文字及可选上下文直接发往你选择的服务，Key 只作为该服务的鉴权凭证发送。近译没有翻译中转服务器。模型 Key 保存在扩展或篡改猴的本机私有存储中；服务商对请求的留存和处理以各自政策为准。

可选 DeepL 连接准备可能提前联系其服务，但不包含正文。查看完整数据说明。
