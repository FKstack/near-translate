# 近译 v0.11.9

修复篡改猴翻译时正常流式响应被误报为“无法连接翻译服务”的问题。

- 正确读取来自不同运行上下文的字节，以及响应头到达前提供的数据流，避免译文被丢弃或读成空内容。
- 网络、超时等全局故障只在翻译栏提示一次，并停止后续请求。原文和已完成译文保留，点击“重试未完成部分”后再继续。
- PostgreSQL 等 DocBook 文档优先翻译正文，跳过顶部导航、版本列表和前后页按钮。Chrome / Edge 共用的整页翻译也包含此次修复，PDF 与文档转换继续保留。

从原安装渠道升级后，刷新已打开的文章页。已保存的 API Key 继续使用，无需重新填写或解锁。

本地验证通过：1,479 项单元测试、18 项扩展整页浏览器测试、两种脚本渠道各 22 个浏览器场景，以及 Chrome / Edge 构建。另用官方 Tampermonkey 5.4.1 和独立测试浏览器验证了 15 段翻译、网络失败集中提示及手动重试恢复。测试使用本机模拟 API 和假 Key，未调用真实付费模型。
