# 阅读模式自定义：以用户任务为中心的竞品分析

研究日期：2026-10-23（Asia/Singapore）。对象：Firefox Reader View、Microsoft Edge Reading mode、Safari Reader、Readwise Reader、Clearly Reader、简悦 SimpRead。本文负责官方资料研究与设计取舍；不把文档阅读冒充完整产品实测。首次使用的浏览器走查与最终实现/安装验证应单独记录。

本轮目标是让用户更快调到适合自己的阅读状态，并在双语核对、长文定位和技术内容之间保持连续性。**选项数量不构成优势；完成任务的步骤、可预测性和恢复成本才是判断标准。** 官方资料只能证明已公开能力，不能证明竞品在某项任务上的实际优劣。

## 1. 证据与产品基线

证据分为三类：

- **事实**：本次联网读取的厂商官方文档、产品页、官方发布者商店说明；近译事实来自改动前源码。
- **判断/设计假设**：由用户任务推导的优先级，需要真实界面和任务验证。
- **待验证**：官方材料未充分说明或当前环境未实测，不能写成“不支持”。

近译改动前已有七类偏好：纸白/暖纸/深色主题、16–28 px 字号、1.5–2.2 倍行高、三档栏宽、衬线/无衬线字体、原文/双语/仅译文、段落专注。设置自动保存。字段定义见 `src/shared/reading.ts`，界面见 `src/reading/ReadingView.tsx`。这说明本次应补足**配置效率、细粒度排版、复用与恢复**，无需重新做一个阅读器。

“未核实”只表示本次证据不足。导出文章与导出阅读配置是两项不同能力；系统主题与任意自定义配色也应分开。

| --- | --- | --- | --- |

### 版本与事实边界

Edge 的旧版 Immersive Reader 文档仍描述 Text preferences、Line focus 和字距等功能；2026-10-23 读取的新版帮助使用 Reading mode、Settings → Appearance settings。不可将新旧两套控件拼成同一实测版本的功能清单。Firefox 当前帮助也已超出早期的亮/暗/暖三主题，不应以旧截图低估它。

Clearly 已有段落双语，简悦已有丰富定制与配置搬迁。因此“有双语”或“能调行距”只达到市场基线；近译需要证明整条任务更顺畅。

## 3. 从用户任务判断哪些可取（判断）

以下优缺点是基于公开能力的任务推导；操作成本尚需走查或对照实测。

| 用户任务 | 值得借鉴 | 用户可能付出的成本/待验证点 | 近译应做出的响应 |
| --- | --- | --- | --- |
| 第一次打开，只想把字放大继续读 | Safari 少量选项；Firefox/Readwise 的 Aa 入口 | 图标是否能让新用户找到；高级项是否压过正文 | 保留有文字的“显示设置”；最先露出一键方案、字号、主题；其余分组折叠 |
| 晚上读长文，不想每篇重调 | Edge/Safari 记忆上次选择；Readwise 系统主题 | 暗色不等于每个人都舒适；Web/移动设置边界可能不同 | 跟随系统、明确浅/暗主题；用户自己的方案优先于产品替用户猜测 |
| 技术文章里看代码、宽表与图片 | 简悦/Clearly 对代码与公式的重视 | 隐藏图片可能连图表信息一起丢；宽代码不应撑破整页 | 代码保留等宽，局部横滚/可选折行；图片可关但默认保留；不把正文排版强加给代码 |
| 读英文并核对中文 | Clearly 段落对照；Edge 翻译入口 | 双语高度变长、原译视觉竞争、调整设置时位置跳动 | 原/双语/译文三态复用已有译文；译文层次可选；调整排版不触发翻译、不丢当前段落 |
| 调了一轮发现不喜欢 | 简单明了的上次偏好记忆 | 单个控件逐项回调很慢；“恢复默认”可能误删个人方案 | 恢复舒适默认与个人方案清楚区分；提供反馈；导入出错保留原设置 |
| 更换设备或分享给家人 | Clearly 配置同步、简悦上传/下载配置 | 登录、订阅、配置覆盖范围、敏感数据夹带 | 本地命名方案与 JSON 配置搬迁；清楚说明只搬排版偏好，不包含正文、历史或密钥 |

## 4. 可执行的设计优先级（建议）

### P0：让用户快速形成自己的阅读习惯

1. **按任务提供少量“阅读方案”**：舒适长读、清爽精读、夜间等有限组合，一次应用主题/字体/字号/间距/栏宽。名称解释用途，显示核心参数；手调后标为自定义。预设是起点，不承诺任何人都读得更快。
2. **分两层设置**：常用层负责方案、主题、字号、字体、栏宽；高级层放段距、字距、对齐、图片/代码与双语呈现。键盘和窄屏用户也能按同样逻辑找到控件。
3. **真实正文即时反馈**：每次改动直接显示在当前文章上，当前段落维持在阅读区；拖动滑块不频繁抢焦点，不让屏幕阅读器持续播报整个文章。
4. **复用与恢复**：保存当前为“我的方案”，可重命名/删除；一键恢复默认；导入/导出仅带排版数据。显示保存成功与失败状态，让用户知道下次是否会保留。
5. **扩大可用范围**：字号可比现有 16–28 px 更宽；段距、字距与对齐作为选配。有限、可验证的主题优先于无限自由调色。新增跟随系统或高对比主题时明确名称和选中状态。

### P1：近译值得验证的差异化

- **双语阅读方案**：把“只看懂内容”“对照精读”做成可理解的视觉选项，控制原译文的层次和节奏；不要只增加一组难懂的数值。
- **调排版也不断线**：按段落锚点维持位置，保持已完成译文和目录定位。用户不因调整字号而重复等待 DeepSeek，也不为找回刚才读到的句子反复滚动。
- **个人方案可带走**：无需账号就能分享/备份自己的排版；导入前校验版本、类型、数值和允许字段，失败不覆盖已有方案。此处是产品目标，不能据资料声称竞品都没有。
- **专注也能快速核对**：聚焦当前段落时保留上下文的可辨识度；原文和译文的联系应可见，不能因淡化原文导致对比度过低。

真正的差异化应表述为：“在本次固定文章和任务中，用户完成设置/双语核对/恢复阅读点的步骤更少或成功率更高。”实现完毕、尚未做多人研究时，不使用“全面超过竞品”。

## 5. 本轮明确不做的范围（取舍）

- 不扩展成 RSS、稍后读、云笔记、账号同步或 EPUB 管理器。这些是另一类用户任务，会增加入口和维护成本。
- 不让用户必须写 CSS/JavaScript 才能使用基本自定义。可编程能力适合熟练用户，本轮用有边界的可见控件解决常见需求。
- 不默认下载网络字体。先使用系统字体栈，避免阅读布局依赖额外网络请求。
- 不在本轮新增摘要、改写、Bionic/速读等功能并宣称提升理解或治疗阅读困难；排版偏好与经过验证的个体效果需要分开。
- 不把“只看文字”设为默认；技术文章的图表、代码和图注可能是正文信息。
- 不保存 URL、文章/译文、API Key 到排版方案或导出文件；对未知字段直接丢弃。

## 6. 用户导向的验收任务

| 场景 | 验收依据 |
| --- | --- |
| 首次使用 | 新用户能从阅读页找到设置，单次点击应用方案；常用调整不需展开高级项 |
| 连续阅读 | 在中段放大字号、改栏宽/行距、切换双语后仍能定位到同一段；不新增 provider 请求 |
| 复用 | 重开阅读模式/刷新后保留有效偏好；保存和恢复个人方案可理解；旧版七字段数据能正常升级 |
| 恢复与搬迁 | 恢复默认不破坏已保存个人方案；合法文件可往返；损坏/未知版本/超大文件不覆盖现设置；导出无内容/密钥 |
| 技术内容 | 宽表/代码只在自身区域滚动；关图/开图可逆；图注不变成无来源孤立文字 |
| 无障碍 | 全程键盘可达，选中态不只靠颜色；200% 缩放控件仍可达；自定义间距不裁切正文或控件 |
| 网络与性能 | 断网仍可打开/调整/恢复方案；改样式不等待模型、不进行正文网络请求 |

无障碍验证可参考 W3C：在可适用文字系统中，把行高调至 1.5 倍、段后距 2 em、字距 0.12 em、词距 0.16 em 时不应丢失内容或功能。**这是覆盖后不破坏内容的测试条件，不要求所有用户采用同一默认值，也不要求产品一定内置这四个控件。** 200% 文字放大也应无内容/功能损失。普通正文的颜色组合以 4.5:1 对比度为基础目标；自定义方案不能只靠较浅颜色区分译文。[文字间距说明][W1]、[文字放大说明][W2]、[对比度说明][W3]

## 7. 待验证与后续证据

- 本文未替六款产品逐一注册付费账号和安装同版本扩展，不对未展示菜单的控件、收费归属或提取质量作否定判断。
- Firefox/Safari 的命名方案、配置导入导出与完整恢复路径，本次核心帮助没有充分证据。
- Clearly 价格页的图标矩阵未被文本读取完整还原；只能确认存在免费/高级/订阅分层，不逐项补猜。
- Readwise 的移动主题不得被宣传为 Web 已有；其外观功能和价格应以文档日期/当前账号为准。
- 已有的原/译三态、局部缓存与阅读锚点需要结合实际实现验证，不能只由字段存在推出体验完成。
- 正式“优于竞品”的结论须提供同文章、同视口、同任务的版本、步骤、成功率和缺失内容记录。

## 本轮落地取舍

竞品研究中的建议是设计候选，不全部等同于本轮承诺。经过职责和首次使用成本评估，本轮采用三个场景起点、常用与高级设置分层、六类主题及有限自定义配色、精细排版与双语层次、固定一个本地“我的样式”、撤销/恢复默认、保存失败重试和版式 JSON 导入导出。个人样式与文件只携带外观，应用时保留原文/双语/仅译文选择。

本轮不做多方案命名、删除与方案筛选，也不加入关图开关；图片与图表沿用现有正文展示。研究中提出的其他候选能力需另行评估。具体交付和验证结果以 [本轮设计](READING_CUSTOMIZATION_DESIGN_2026-10-23.md) 及最终验证记录为准，不能仅凭本文研究建议宣称已实现或已优于竞品。
