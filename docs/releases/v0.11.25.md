# 近译 v0.11.25 · Chrome / Edge

## 修复

- 修复 Qt 官方文档等没有声明 DOCTYPE 的兼容模式页面上，右侧近译悬浮按钮被定位到可视窗口下方的问题。
- 按页面渲染模式读取真实窗口尺寸；长页面、窗口缩小、滚动和拖拽后，按钮保持在可视范围内。

## 安装与升级

在本 Release 附件中选择 `near-translate-chrome-v0.11.25.zip` 或 `near-translate-edge-v0.11.25.zip`。已有用户先备份程序文件，再将解压后的文件替换到原扩展加载目录，在扩展管理页点击“重新加载”，最后刷新已打开的网页。请沿用原目录和扩展身份，以保留浏览器中已有的设置。

## 发行范围与限制

本次基于 GitHub main 发布，仅发行 Chrome 和 Edge 扩展及校验文件。不上传新版篡改猴脚本，不部署 Pages，也不更新 GitHub 脚本渠道或 Greasy Fork 同步源；两种脚本继续提供此前的已发布版本。

此修复不增加权限或翻译请求。浏览器设置页、扩展商店等浏览器禁止注入的页面仍不能显示网页悬浮按钮。其他分支中的本地试验功能不包含在本次发行中。

回归覆盖标准模式和兼容模式长页面，并核对初次显示、刷新、窗口缩小、滚动及拖拽后的按钮位置。
