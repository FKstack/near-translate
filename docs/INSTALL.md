# 近译安装与使用

## 安装

使用当前桌面版 Chrome 或 Edge。ZIP 包需要先解压，加载时选择包含 `manifest.json` 的文件夹，不是 ZIP 本身，也不是项目源码根目录。

当前版本 **0.7.0**。源码仓库不包含构建产物。在项目根目录使用 Node.js 24+、npm 11+ 执行：

```powershell
npm ci
npm run build        # Chrome
npm run build:edge   # Edge
```

需要 ZIP 时执行 `npm run zip` 或 `npm run zip:edge`，在 `.output` 下找到生成文件并解压。已有安装继续使用原来加载的文件夹路径，更新程序文件后点击「重新加载」并刷新网页；旧版 DeepSeek Key、模型和开关兼容保留。

| 浏览器 | 管理页 | 本项目构建目录 |
| --- | --- | --- |
| Chrome | `chrome://extensions` | 项目根目录下的 `.output/chrome-mv3` |
| Edge | `edge://extensions` | 项目根目录下的 `.output/edge-mv3` |

1. 在管理页启用「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择对应目录。
3. 将「近译」固定到浏览器工具栏，便于打开设置与 PDF。
4. 开发更新后，在管理页点击扩展的「重新加载」，再刷新使用中的网页。

## 配置模型与 API

0.1.1 修复了旧版原生网络调用被误报为网络失败的问题。已经原位更新的用户保留现有安装目录和Key；刷新原网页即可，无需移除扩展或重新填写Key。

点击近译图标 →「翻译设置」，选择 API 服务商，核对基址和模型名，填写该服务的 Key 并保存。需要时接受浏览器对该 API 域名的访问请求。API 用量由所选服务商或网关的账户支付。

| 预设 | 接入方式 |
| --- | --- |
| DeepSeek | 默认服务，默认 `deepseek-flash`、非思考模式。 |
| OpenAI | Chat Completions 接口，模型名按账户权限填写。 |
| Google Gemini | Google 官方 OpenAI 兼容接口。 |
| 通义千问（百炼） | 百炼 OpenAI 兼容接口，地区与账户须对应，可修改基址。 |
| Kimi / Moonshot | Moonshot OpenAI 兼容接口，可修改基址。 |
| 硅基流动 | OpenAI 兼容接口。 |
| OpenRouter | OpenAI 兼容路由，可选择账户支持的 Claude 等模型。 |
| Ollama | 本机 OpenAI 兼容接口，默认 `http://localhost:11434/v1`，填写已安装模型名，无需 Key。 |
| 自定义 | 提供 OpenAI Chat Completions 流式 SSE 的服务或网关；是否需要 Key 取决于网关。 |

预设是可编辑的配置起点，不保证账户拥有模型权限或额度。0.7.0 的协议验证使用模拟响应，未逐一验证各服务真实连接、翻译质量或延迟。原生 Anthropic Messages 和 OpenAI Responses 协议尚未实现；Claude 可经 OpenRouter 或兼容网关使用。

Base URL 填接口根路径，例如 `https://api.deepseek.com` 或 `https://api.openai.com/v1`，程序会追加 `/chat/completions`；也接受以 `/chat/completions` 结尾的地址。地址不得含用户名、密码、查询参数或片段。远程地址须使用 HTTPS，HTTP 仅支持本机 `localhost`、`127.0.0.1` 等回环地址。

「JSON 模式」用于发送 `response_format: { type: 'json_object' }`。接口不支持该参数时请关闭；关闭后词典、整页和句法输出仍必须满足提示词规定的结构并通过校验。模型需支持聊天消息和流式文本输出。

默认模型为 **deepseek-flash**，默认关闭思考模式。可以按 DeepSeek 官方支持列表修改模型名，默认访问官方 `https://api.deepseek.com/chat/completions`。

0.2.0 单词卡分为「本句含义」和「常见义项」。前者给出当前句中的词性、词义和说明；后者按词性列出其他常见含义，默认展开。点击「参考原句」可查看用于判断的上下文，「复制」会复制两部分完整内容。未提供上下文时显示「参考释义」，明确提示不能确定本句含义。

每个服务商独立保存一份模型、基址、JSON 模式和 Key，切换服务不会借用其他服务的 Key。当前服务基址未变时，Key 输入框留空会保留 Key；修改地址后需重新填写要发送给新地址的 Key，留空不会把旧 Key 带到新地址。点击「删除已保存的 Key」再保存才会删除。Key 只存本机受信任扩展存储、不跨设备同步；浏览器存储本身不提供密码保险库式加密。不要把 Key 写进项目文件、Issue、截图或 Git。详见 [隐私说明](PRIVACY.md)。

「附带上下文」默认开启：单词或短语使用所在句，完整句段使用邻近一句，最多额外 600 字符。关闭后只发送选中内容。

## 长难句拆解

0.6.0 在卡片原句上增加语法彩色标注，与原来的「长难句拆解」开关一同开启或关闭：主语为蓝色、谓语为红色、宾语为橙色、从句为紫色、修饰成分为青绿色。分块说明使用对应颜色；不确定或不可再分的混合成分保持中性，不凭空添加原句没有的宾语或从句。

点击原句中的彩色片段可定位到对应分块，点击分块可返回原句的对应位置；键盘可用 Tab 聚焦，再按 Enter 或空格操作。定位仅滚动卡片内部，卡片原句完整保留所选文字、空白和标点，不改写网页 DOM 或原来的选区。关闭「长难句拆解」后，拆解和所有彩色标记一起移除，正常译文保留。

语法分类由原来的同一次分析请求返回，彩色标注和双向定位不增加 API 调用，也没有新增设置、依赖、权限或 Key 存储。

0.5.0 在「翻译设置」加入「长难句拆解」开关，默认开启。选中单个英文长句并点击附近的「译」，先显示正常中文译文，随后在同一张卡片的译文下方补充：

- 句子主干：抽出核心主语、谓语、宾语或补语，附中文释义和结构说明。
- 分块阅读：按原文顺序标出主干、从句、介词短语或其他修饰成分，并解释它们的关系。
- 阅读顺序：建议先读主干，再补回各层修饰关系。

拆解区域默认展开，可以点击标题折叠；较长结果在卡片内滚动，不会把关闭与复制按钮挤出屏幕。复制按钮仍只复制正常译文。分析属于句法参考，遇到歧义应结合上下文判断。

拆解使用当前服务、模型和已保存的 Key，会在句子翻译成功后额外发起一次请求。关闭该开关后只显示译文；单词、多句段落和整页翻译不触发拆解。当前支持至少 6 个英文词、最多 2,000 字符的单句或未加句末标点的句段，较长或多句内容请分句选择，原本的句段翻译上限保持。

拆解失败不会覆盖已返回的译文，点击「重试拆解」只重试该分析。关闭卡片、按 Esc、改选文字、导航或关闭开关都会取消分析；原 Key 和其他设置保留。

## 网页划词

0.4.1 修复青色主按钮的切换行为：首次点击翻译，已翻译完成后再点击同一按钮恢复英文原文，移除中文译文并结束动态翻译，不会重复调用 DeepSeek。恢复后再点击可重新翻译。翻译进行中点击仍然停止；部分翻译完成后停止的页面也可以再次点击恢复原文。

0.4.0 增加整页批量加速：短段落合并请求，最多 32 路并发，译文逐段显示。原 DeepSeek Key、模型和 API 地址保持不变。已有页面在扩展更新后需要刷新；部分批次失败时只重试缺失部分，已成功返回的段落不会重复请求。

0.3.0 增加网页整页中英对照。保留现有安装身份和已保存的 DeepSeek Key，在扩展管理页重新加载扩展，然后刷新原网页，即可看到页面右侧翻译栏。

点击青色翻译按钮后，英文标题、段落、列表和表格下面会逐步出现中文译文；上方齿轮打开设置，文档按钮「显示原文」移除全部译文，翻译过程中再次点击青色按钮可停止。单段失败后可点击「重试失败段落」，成功段落不会重复请求。鉴权、余额、限流或连接中断时会停止剩余任务，避免持续失败请求。

代码块、代码编辑器、图片、输入框、可编辑区域、隐藏内容、标记不翻译的内容和主要为中文的段落会跳过。行内代码保留原始 DOM，并随所在段落提供字面值帮助翻译；不识别图片内文字。整页模式仅处理当前主文档，内嵌 iframe 保留原样。

只有主动点击才会把英文正文分批发送到当前选择的 API，使用该服务已保存的 Key 和模型。开启整页翻译后，动态追加的英文也会继续翻译，直到停止或显示原文。每批最多 16 个短段落、目标约 1,600 个英文字符，最多 32 路并发；每次最多 1,500 个段落，超长段落分块后合并；正文和译文只保存在当前页内存，不持久化。不同服务的额度和并发限制可能不同，遇到限流请稍后手动重试。

在设置页点击「启用网页划词」，接受浏览器的 HTTP(S) 网页访问请求。该权限用于在选择文字后自动显示按钮。

刷新此前打开的网页，然后双击英文单词或拖选英文句子/段落，松开鼠标后点击「译」。单词显示词义、词性与语境解释，句段逐步显示中文译文。点击「复制」复制结果，点击 × 或按 Esc 关闭。

只有点击「译」才会发送选中文字和可选的有限上下文。新选区会取消旧请求；一次最多 12,000 字符，超出时请分段。关闭「启用翻译」会暂停网页和 PDF 的翻译，不影响 PDF 阅读。

浏览器设置页、扩展商店及其他受限页面不能显示按钮。iframe 需要对应网页权限。复杂网页组件的选择行为可能受网站本身影响。

## PDF 划词

在线 PDF：打开 PDF 标签页 → 点击近译图标 →「用阅读器打开当前 PDF」。地址不必以 `.pdf` 结尾。也可在阅读器的地址栏粘贴在线 PDF 链接，按「打开在线 PDF」。未授权的网站会请求访问权限。

本地 PDF：点击「选择本地 PDF / 输入 PDF 链接」→「打开本地 PDF」选择文件，无需授予所有本地文件访问权限。

在近译阅读器中双击单词或拖选句段，再点「译」。支持翻页、页码跳转、缩放、搜索和密码文件。整份 PDF 在阅读器中解析，不作为翻译请求上传到模型服务；仅发送所选文本和可选上下文。密码只保留于当前加载过程。

浏览器内置 PDF 阅读器禁止注入该浮层，因此必须进入近译阅读器。只有图片、没有文字层的扫描页会提示暂不支持 OCR；已有 OCR 文字层的文件可以选词。

需要登录、带临时 blob 地址或服务器拒绝下载的在线 PDF，可能无法直接加载。此时下载 PDF，再在近译中打开本地文件。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 没有「译」按钮 | 检查总开关、网页权限；授权或重载扩展后刷新网页；PDF 要在近译阅读器内打开。 |
| API Key 无效 | 核对当前服务、基址与 Key；修改地址后需重新填写 Key。 |
| 模型不存在或参数不支持 | 核对账户可用模型和 Chat Completions 兼容地址，接口不支持 JSON 模式时关闭。 |
| 本地接口无法连接 | 确认服务已启动、模型已安装，核对回环基址及 API 域名权限，检查服务自身的来源访问设置。 |
| 余额不足或请求过多 | 按卡片提示检查账户额度，稍后主动重试。 |
| 等待或网络失败 | 首连接超时 25 秒，整体最长 90 秒；检查网络后点击重试。 |
| 译文被截断 | 缩小选区后重试，保留更短的段落。 |
| 在线 PDF 无法打开 | 下载到本机，使用文件选择器打开。 |
| 扩展更新后连接中断 | 重新加载扩展并刷新网页；重新打开 PDF 阅读器。 |
