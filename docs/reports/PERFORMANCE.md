## 旧 JSON-RPC 批处理与页内缓存（2026-10-21，历史）

旧候选每次 JSON-RPC 最多 32 项、合计 4,800 个 UTF-16 单元，请求体不超过 64 KiB；`requestAlternatives: 0`。所有页面、划词与 PDF 共用串行队列，每次完成后至少间隔 1,050 ms。批次严格校验 RPC ID、返回数量和全部非空文本后按原序回填，长段无损重组，不自动拆单重试。429 停止后续任务并保留至少 60 秒的会话冷却；这些旧协议失败不代表上表当前 OneShot 的结果。

正文采集优先唯一可见 article，再选择唯一可见 main，否则覆盖 body。页内纯文本缓存最多 1,500 项、约 2 MiB 文字预算，恢复原文保留缓存；导航、连接配置或翻译方式变化、暂停/撤权和销毁会清空。模型调度默认仍为每批最多 16 项、目标 1,600 字符、最多 32 路并发。

两次实际安装长文试译均未完成全文：

| 请求完成后最小间隔 | 首屏可读 | 到停止 | 完成段落 | HTTP 结果 |
| --- | ---: | ---: | ---: | --- |
| 200 ms | 约 2.2 秒 | 约 10.5 秒 | 125 / 251 | 6 次 200，第 7 次 429 |
| 1,050 ms | 2.329 秒 | 6.561 秒 | 59 / 251 | 2 次 200，第 3 次 429 |

1,050 ms 方案共提交 3 次请求、12,008 个原文字符，其中 HTTP 200 请求对应 7,274 字符；包含 429 请求的提交字数不能算作成功翻译量。原始报告位于 `.output/go-page-deepl-paced-1a8819999ed29ca9d86db71adaa1a1e129950aeb.json`。已停止进一步真实网络测试，没有 DeepL 全文快速完成的成功结果。

服务端具体阈值与限流维度未公开，不能确认请求频率是唯一成因，也不能断定 IP 封禁或固定包大小限制。1,050 ms 是保守客户端策略，其实际全文试译仍失败，不提供全文耗时或可用性承诺。

比较性能时应区分新文档无缓存、部分缓存与恢复原文后的缓存复用，并记录正文范围、唯一文本数、实际请求数和失败数；缓存命中减少网络请求，不能记为翻译服务吞吐量提升。首屏可读与全文成功需分别报告。

后台提供仅受信任扩展页可读取的本地无正文指标：累计请求/条目/字数、并发、状态和 fetch 起止时间，保留最近最多 256 条请求记录；不记录文本或 Key、不上传遥测。fetch 等待时间不包含完整的译文读取、解析及页面回填，全文时间需另从用户点击计至页面终态。

### 瓶颈与改动

1280 像素宽独立浏览器中的只读采样为 315 段、303 个唯一文本、54,201 个唯一英文字符，约 8,937 词，139 段少于 40 字符。实际用户浏览器因布局与可见项差异提取 314 段。提取加完整失效复验约 24 毫秒，远小于网络等待。

旧版每个标题、目录项、列表项和正文段落各发一次请求，仅 2 并发。新版将短段合并，每批最多 16 项、约 1,600 字符，最多 32 并发，减少重复首响应等待；合法 NDJSON 段落行到达即显示，不等整批完成。长段落可并行拆分并按原序重组。批次中断后保留已完成项，手动重试只发送缺失部分。

没有变更模型或 API 地址，没有缩写正文、减少翻译范围，也没有用预制译文替代 API。鉴权、余额、限流和连接错误仍会停止剩余队列。软件总活动请求上限为 64；官方接口并发说明见 [DeepSeek Rate Limit & Isolation](https://api-docs.deepseek.com/quick_start/rate_limit/)。

优化前实测时，安装目录是 0.3.0，用户浏览器的后台 manifest 仍显示 0.2.0；其文字请求协议与逐段 2 并发行为保持兼容。本次已通过扩展自身重载，并在实际运行态确认 manifest 为 0.4.0。

### 复现与证据

在本项目原安装目录及同一个 Edge profile 下，可运行：

```powershell
npm run benchmark:installed -- --label verification --reload --timeout-ms 90000
```

脚本打开用户指定的公开网页，点击真实悬浮栏，通过 DOM 状态计时，从点击到全部段落与批次完成；临时测试页在结束后移除。它不替换 fetch、不注入模拟 API，也不读取凭证存储。原始结果在 `.output/go-page-baseline.json`、`.output/go-page-optimized-32.json`、`.output/go-page-optimized-repeat.json`，发布时合并到 `artifacts/performance-go-v0.4.0.json`。
