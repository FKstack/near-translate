# 近译安装与使用

适用于当前桌面版 Chrome / Edge。普通用户下载 Release 中的 ZIP 即可安装，无需 Node.js、npm 或编译工具。

## 下载 v0.11.2

打开 [v0.11.2 Release](https://github.com/FKstack/near-translate/releases/tag/v0.11.2)，在 **Assets** 中选择与你的浏览器对应的安装包：

| 浏览器 | 安装包 | 扩展管理页 |
| --- | --- | --- |
| Chrome | [near-translate-chrome-v0.11.2.zip](https://github.com/FKstack/near-translate/releases/download/v0.11.2/near-translate-chrome-v0.11.2.zip) | `chrome://extensions` |
| Edge | [near-translate-edge-v0.11.2.zip](https://github.com/FKstack/near-translate/releases/download/v0.11.2/near-translate-edge-v0.11.2.zip) | `edge://extensions` |

请选择上表中的安装包；GitHub 自动提供的 **Source code (zip / tar.gz)** 是源码，不能直接加载为扩展。近译目前采用开发者模式加载安装包，尚未提供浏览器商店安装。

## 安装到浏览器

1. 将下载的 ZIP **全部解压到长期保留的固定文件夹**，例如 `D:\Apps\near-translate`。不要放在会自动清理的临时目录；安装后也请保留文件夹。
2. 在地址栏输入 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge），按回车。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择**直接包含 `manifest.json` 的文件夹**。如果解压工具多创建了一层文件夹，请继续进入，直到能看到 `manifest.json`；不要选择 ZIP 文件。
5. 在扩展列表确认显示「近译 · 阅读与翻译」及版本 **0.11.2**。通过浏览器的「扩展」菜单将近译固定到工具栏。
6. 打开或刷新一篇普通网页，点击近译图标 →「阅读当前网页」，即可先体验本地阅读。

如果显示「无法加载清单」，先检查是否完整解压、选择的文件夹是否直接包含 `manifest.json`。浏览器设置页、扩展商店等受限页面不能开启网页阅读或划词，请换成普通文章页。

### 可选：校验下载文件

同一 Release 提供 [SHA256SUMS.txt](https://github.com/FKstack/near-translate/releases/download/v0.11.2/SHA256SUMS.txt)。下载后可在 PowerShell 中计算安装包的 SHA-256，与文件中对应包名的值比较：

```powershell
Get-FileHash .\near-translate-chrome-v0.11.2.zip -Algorithm SHA256
# Edge 用户改为 near-translate-edge-v0.11.2.zip
```

## 已有用户升级

开发者模式安装的版本需要手动更新。**先保留原扩展，并记录它的 ID、加载路径和翻译设置**；API Key 请保留在你自己的安全位置，不要放入截图、Issue 或公开文件。

阅读样式可在阅读模式 →「显示设置」→「导出版式」备份。该文件只导出**当前显示偏好**，不含 API Key、翻译服务配置、文章或单独保存的「我的样式」；如需备份已保存样式，先点击「应用我的样式」，再导出。

1. 下载与你原安装浏览器对应的新 ZIP，先解压到另一临时文件夹，确认其中存在 `manifest.json`。
2. 备份原扩展程序文件夹，再将新包的程序文件完整替换到**原来加载的同一路径**。注意保持 `manifest.json` 直接位于原加载目录，不要多嵌套一层文件夹。
3. 在扩展管理页点击原近译卡片的「重新加载」。不要先移除原扩展，也不要从另一路径另装一份。
4. 确认版本为 **0.11.2**、扩展 ID 与升级前一致，再核对翻译方式、模型、语言方向和阅读样式。刷新已打开的网页；PDF 阅读器请关闭后重新打开。

设置保存在浏览器的扩展存储中。沿用原浏览器配置、原加载路径和原扩展身份通常可继续使用已有设置；更换目录、浏览器配置或移除后重装可能改变扩展身份或清除数据，不能保证配置自动迁移。若需恢复版式，使用「导入版式」；翻译设置请按自己的记录重新配置。

## 第一次使用

**先阅读，无需登录或 API Key。** 打开文章后，点击扩展图标 →「阅读当前网页」。阅读模式中的「显示设置」可调整主题、字号、行距和栏宽，也可保存「我的样式」。只有需要翻译时才配置服务。

全新安装且没有已保存设置时，默认选择「DeepL 免费翻译」，默认语言为「自动识别 → 简体中文」。读取或保存设置不会自动发送试译，也不会自动翻译当前文章。沿用原扩展身份升级时保留翻译方式、模型与地址；旧版 Key 需在设置页完成口令加密迁移后使用。

1. 点击近译图标，或打开「翻译设置」，点击「启用免费翻译」。
2. 接受浏览器对 HTTP(S) 网页和 `oneshot-free.www.deepl.com` 服务域名的访问请求，一次完成网页与免费服务授权。无需登录、API Key 或 Cookie；拒绝授权不会改动原配置，仍可本地阅读。
3. 可选点击「测试免费翻译」。只有这次明确点击才发送固定公开英文 `The library opens at nine in the morning.`，固定译为简体中文；不读取当前文章、PDF 或选区，不改变已保存的语言方向。打开「连接测试会发送什么？」可先查看例句。结果与耗时只代表当次连接。
4. 刷新此前打开的网页。点击「翻译正文」、原页青色翻译按钮，或选择文字后点击「译」，才开始对应内容的翻译。

「启用免费翻译」会主动切换到 DeepL 并开启翻译，保留原模型配置与各服务 Key；以后可在「翻译方式」切回「大模型 API」并保存。它不依赖手动填写模型表单，也不启用独立的「可选连接加速」权限。

## 选择源语言与目标语言

在「翻译设置」调整「源语言」「目标语言」，再点击「保存设置」；扩展面板的「语言设置」也可进入此页。网页整页、网页/阅读层划词、阅读正文与 PDF 选文共用保存后的语言方向。更改语言会取消旧任务并使旧语言方向的页内缓存失效，不会自动重译文章。

源语言支持「自动识别」及以下 16 项；目标语言支持同样 16 项：

| 中文 | 亚洲其他语言 | 欧洲语言 | 其他 |
| --- | --- | --- | --- |
| 简体中文、繁体中文 | 日语、韩语、印地语、印尼语、土耳其语、越南语 | 英语、德语、法语、西班牙语、俄语、葡萄牙语、意大利语 | 阿拉伯语 |

自动识别由翻译服务判断来源；来源明确时可手动指定，例如「中文 → 英语」或「日语 → 简体中文」。显式选择相同源/目标语言时，同语言正文会跳过。各模型服务仍需具备所选语言的翻译能力。

英语学习功能保留限定范围：模型词典仅用于英语单词译为简体或繁体中文；长难句拆解仅用于英语译为简体中文，需显式选择英语，或自动源下网页提供英语内容语言提示。语言无法确定时不追加英语句法请求；PDF 不使用阅读器界面语言推断文档语言，需要拆解英文 PDF 时请显式选择英语。其他语言、其他目标方向和 DeepL 模式使用普通文本译文，不显示模型词典或句法拆解。

## 网页阅读模式

阅读模式无需登录或 API Key。打开普通 HTTP/HTTPS 文章详情页，通过以下任一入口进入：网页侧栏「阅读模式」、扩展图标 →「阅读当前网页」，或 `Alt+Shift+R`。快捷键和侧栏需要页面已加载近译内容脚本；Popup 可借助当前页的 `activeTab` 授权先打开本地阅读，无需先配置翻译服务。扩展更新后请刷新已打开的网页。浏览器设置页、扩展商店等受限页面不能使用此入口，PDF 使用下文的独立阅读器。

界面保留文章正文、代码、图片、列表和表格，提供章节目录、阅读进度、当前段落专注，以及纸白/暖纸/深色主题、衬线/无衬线字体、16–28 px 字号、1.5–2.2 倍行距和三档栏宽。窄屏通过抽屉打开目录与显示设置。

「原文」「双语」「仅译文」只切换显示，不自动请求翻译；尚无译文或翻译未完成时保留原文。需要翻译时先配置服务及网页权限，再点击「翻译正文」。进行中可以停止，失败后可手动重试未完成段落。阅读内也可选择支持语种的文字使用既有划词卡片。原网页成功译文可本地复用，同一文档内关闭再打开也可复用仍在有界缓存中的结果；导航、语言方向、连接或权限变化会使缓存失效。

按 `Esc` 或点击「退出」回到原网页并恢复进入前的位置和焦点；窄屏抽屉打开时，`Esc` 先关闭抽屉。工具栏「返回原网页当前位置」及段落的「回到原文位置」可定位原网页对应节点，前提是该节点仍然存在。

正文在本地提取，不持久化原文、译文或浏览历史；只保存显示偏好。图片可能从原站正常加载，不能把本地阅读理解为整个浏览器完全零网络。点击翻译才发送相应未缓存正文，继续使用原引擎与共享限流保护，既有 DeepL 耗时和 429 限制仍适用。未能提取时可返回原页或等正文加载后重试，阅读模式不保证覆盖所有动态页面。详见[隐私说明](PRIVACY.md)与[阅读模式设计记录](../reports/READING_MODE_DESIGN_AND_VALIDATION_2026-10-22.md)。

## 不使用 API Key：DeepL 免费翻译

优先使用上文的「启用免费翻译」完成授权。也可打开「翻译设置」，在「翻译方式」选择「DeepL 免费翻译（实验性，无需登录或 Key）」并保存；此保存只申请 `oneshot-free.www.deepl.com` 的服务域名权限，网页权限可通过「启用网页划词」另行授权。旧版缺少该域名权限时请重新授权。普通翻译无需登录、Key、Cookie 或请求头修改权限。

此模式支持整页、阅读正文、划词和 PDF 选文翻译，按已保存的源/目标语言处理，默认自动识别并译为简体中文。匿名 OneShot 请求每批最多 32 项、合计 1,500 个 UTF-16 单元，请求体最多 64 KiB、响应最多 1 MB；所有页面与选区共享最多 8 个在途请求，相邻执行启动至少间隔 100 ms，滚动 12 秒内最多启动 30 次。这是客户端保护策略，不是 DeepL 官方额度。已经启动的任务即使取消也不退还窗口计数，空闲和 429 不重置启动历史，记录按时间自然过期。长难句拆解和词典解释需要切换到大模型 API，并符合上文的英语学习语言方向。切换模式会取消正在执行的翻译，保留原有模型配置。

自然遇到 429 时，扩展会停止后续任务并保留已完成译文，在面板或当前翻译界面显示冷却倒计时。至少等待 60 秒，服务要求更长时等待更久；期间重试入口不可用。倒计时结束只恢复手动操作入口，需要自行点击「重试」「重试失败段落」或「测试免费翻译」，不会自动继续文章、自动重试或自动改用其他服务。后台休眠、重开面板或切换翻译方式不会清零同一浏览器会话中的 DeepL 冷却。倒计时是本地等待提示，不表示上游一定恢复，不保证翻译速度或解决 429。

第五轮的通用尾部装包改进，使该Go网页从38次请求减少至37次，仍免登录、无需API Key。实际Edge全新标签页、无扩展译文缓存的一轮完成251段/53,505字符，37次HTTP200；首段正文1.420秒、初始4段1.863秒、全文14.295秒，导航到全文19.664秒。但同版本约94秒后再开新标签页，在第21请求429，仅完成118段。**全文10秒未达，429尚未可靠解决，不能把成功单轮当稳定保证。** 当前保留原8路/100ms/30次每12秒保护及已回归的装包改进；更激进候选均已撤下。研究、所有失败轮和限定结论见 [第五轮报告](../reports/DEEPL_PERFORMANCE_V5_2026-10-22.md)。

先前18秒与14.8秒的窗口结果保留在 [第二轮](../reports/DEEPL_PERFORMANCE_V2_2026-10-22.md) 和 [第三轮](../reports/DEEPL_PERFORMANCE_V3_2026-10-22.md)。旧缓存重译不是新标签速度；上游缓存、负载和网络不受控，不保证长期相同耗时。可选元数据连接准备沿用第四轮；本轮未更改匿名正文预算、账号身份或模型Key。

可选连接加速使用已声明的 `declarativeNetRequestWithHostAccess` 权限；设置页可以启用或关闭，历史已有该权限时显示为已启用。只有DeepL及网页/服务权限均开启时，顶层可见HTTP(S)非PDF文档在document_start发送不含正文/URL的准备消息。后台固定OPTIONS请求不含Cookie、API Key、正文或Referrer；规则74002只给自身固定地址OPTIONS加两个标准ACR协商头，不修改Origin、UA、POST或响应。准备可能在未点击时联系DeepL，正文仍只在点击后发送。所有标签共享至少30秒的准备调度预留间隔（不等于实际HTTP间隔），trusted session时间戳跨worker重启保留；5秒总期限含排队，取消及429复用共享调度器，普通POST不依赖此能力。没有新增必需权限或依赖包。

## 配置模型与 API

点击近译图标 →「翻译设置」，选择「大模型 API」，先在「API Key 保护」创建独立解锁口令，再选择 API 服务商，核对基址和模型名，填写该服务的 Key 并保存。需要时接受浏览器对该 API 域名的访问请求；包括 DeepSeek 在内，API 主机权限都按需申请。API 用量由所选服务商或网关的账户支付。

### 模型密钥库与升级迁移

0.11.1 起，API Key 使用口令加密保存。口令为12–128字符，空格属于口令；请使用独立的长口令，不要把 API Key 当作口令。设置页不会回显已有 Key，也不会把解锁口令发往网络。

浏览器重启后，在设置页输入口令解锁；同一浏览器会话内的后台休眠不要求重复输入。可手动锁定、更换口令。锁定时停止模型请求，免费翻译、本地阅读和无鉴权的本机模型仍可使用。

旧版本保存的 Key 需要先设置口令完成迁移；迁移前不会用于模型请求。系统会先保存并验证密文，再清理旧明文；失败时保留原数据供恢复，请按提示重试。不要先卸载扩展，也不要为了迁移把 Key 贴到公开 Issue。

口令不能找回，遗失后无法解密已有 Key；请妥善保存，并保留自己所用 API 服务的凭证恢复渠道。更换口令时如提示「新口令已生效」，请使用新口令重新解锁。

| 预设 | 接入方式 |
| --- | --- |
| DeepSeek | 模型模式的默认预设，默认 `deepseek-flash`、非思考模式；全新安装默认翻译方式为 DeepL。 |
| OpenAI | Chat Completions 接口，模型名按账户权限填写。 |
| Google Gemini | Google 官方 OpenAI 兼容接口。 |
| 通义千问（百炼） | 百炼 OpenAI 兼容接口，地区与账户须对应，可修改基址。 |
| Kimi / Moonshot | Moonshot OpenAI 兼容接口，可修改基址。 |
| 硅基流动 | OpenAI 兼容接口。 |
| OpenRouter | OpenAI 兼容路由，可选择账户支持的 Claude 等模型。 |
| Ollama | 本机 OpenAI 兼容接口，默认 `http://localhost:11434/v1`，填写已安装模型名，无需 Key。 |
| 自定义 | 提供 OpenAI Chat Completions 流式 SSE 的服务或网关；是否需要 Key 取决于网关。 |

预设是可编辑的配置起点，不保证账户拥有模型权限或额度。0.7.0 的协议验证使用模拟响应，未逐一验证各服务真实连接、翻译质量或延迟。原生 Anthropic Messages 和 OpenAI Responses 协议尚未实现；Claude 可经 OpenRouter 或兼容网关使用。

Base URL 填接口根路径，例如 `https://api.deepseek.com` 或 `https://api.openai.com/v1`，程序会追加 `/chat/completions`；也接受以 `/chat/completions` 结尾的地址。地址不得含用户名、密码、查询参数或片段。远程地址须使用 HTTPS，HTTP 仅支持本机 `localhost`、`127.0.0.1` 等回环地址。

「JSON 模式」用于发送 `response_format: { type: 'json_object' }`。接口不支持该参数时请关闭；关闭后词典、整页和句法输出仍必须满足提示词规定的结构并通过校验。模型需支持聊天消息和流式文本输出。

模型模式的 DeepSeek 默认模型为 **deepseek-flash**，默认关闭思考模式。可以按 DeepSeek 官方支持列表修改模型名，默认访问官方 `https://api.deepseek.com/chat/completions`。

0.2.0 单词卡分为「本句含义」和「常见义项」。前者给出当前句中的词性、词义和说明；后者按词性列出其他常见含义，默认展开。点击「参考原句」可查看用于判断的上下文，「复制」会复制两部分完整内容。未提供上下文时显示「参考释义」，明确提示不能确定本句含义。

每个服务商独立保存一份模型、基址、JSON 模式和加密 Key，切换服务不会借用其他服务的 Key。当前服务基址未变时，Key 输入框留空会保留 Key；修改地址后需重新填写要发送给新地址的 Key，留空不会把旧 Key 带到新地址。新增、删除 Key 或修改已有 Key 的服务地址前需解锁密钥库。点击「删除已保存的 Key」再保存才会删除。Key 不跨设备同步；加密不能保护已解锁浏览器中被恶意程序或调试权限访问的运行内存。不要把 Key 写进项目文件、Issue、截图或 Git。详见 [隐私说明](PRIVACY.md)。

「附带上下文」默认开启：单词或短语使用所在句，完整句段使用邻近一句，最多额外 600 字符。关闭后只发送选中内容。

## 长难句拆解

0.6.0 在卡片原句上增加语法彩色标注，与原来的「长难句拆解」开关一同开启或关闭：主语为蓝色、谓语为红色、宾语为橙色、从句为紫色、修饰成分为青绿色。分块说明使用对应颜色；不确定或不可再分的混合成分保持中性，不凭空添加原句没有的宾语或从句。

点击原句中的彩色片段可定位到对应分块，点击分块可返回原句的对应位置；键盘可用 Tab 聚焦，再按 Enter 或空格操作。定位仅滚动卡片内部，卡片原句完整保留所选文字、空白和标点，不改写网页 DOM 或原来的选区。关闭「长难句拆解」后，拆解和所有彩色标记一起移除，正常译文保留。

语法分类由原来的同一次分析请求返回，彩色标注和双向定位不增加 API 调用，也没有新增设置、依赖、权限或 Key 存储。

0.5.0 在「翻译设置」加入「长难句拆解」开关，默认开启。当前仅在模型模式、英语 → 简体中文方向生效，英语来源的确认规则见上面的语言说明。选中单个英文长句并点击附近的「译」，先显示正常中文译文，随后在同一张卡片的译文下方补充：

- 句子主干：抽出核心主语、谓语、宾语或补语，附中文释义和结构说明。
- 分块阅读：按原文顺序标出主干、从句、介词短语或其他修饰成分，并解释它们的关系。
- 阅读顺序：建议先读主干，再补回各层修饰关系。

拆解区域默认展开，可以点击标题折叠；较长结果在卡片内滚动，不会把关闭与复制按钮挤出屏幕。复制按钮仍只复制正常译文。分析属于句法参考，遇到歧义应结合上下文判断。

拆解使用当前服务、模型和已保存的 Key，会在句子翻译成功后额外发起一次请求。关闭该开关后只显示译文；单词、多句段落和整页翻译不触发拆解。当前支持至少 6 个英文词、最多 2,000 字符的单句或未加句末标点的句段，较长或多句内容请分句选择，原本的句段翻译上限保持。

拆解失败不会覆盖已返回的译文，点击「重试拆解」只重试该分析。关闭卡片、按 Esc、改选文字、导航或关闭开关都会取消分析；原 Key 和其他设置保留。

## 网页划词

0.4.1 修复青色主按钮的切换行为：首次点击翻译，已翻译完成后再点击同一按钮恢复英文原文，移除中文译文并结束动态翻译，不会重复调用 DeepSeek。恢复后再点击可重新翻译。翻译进行中点击仍然停止；部分翻译完成后停止的页面也可以再次点击恢复原文。

0.4.0 增加整页批量加速：短段落合并请求，最多 32 路并发，译文逐段显示。原 DeepSeek Key、模型和 API 地址保持不变。已有页面在扩展更新后需要刷新；部分批次失败时只重试缺失部分，已成功返回的段落不会重复请求。

0.3.0 增加网页整页中英对照。保留现有安装身份和已保存的 DeepSeek Key，在扩展管理页重新加载扩展，然后刷新原网页，即可看到页面右侧翻译栏。

点击青色翻译按钮后，符合当前语言设置的标题、段落、列表和表格下面会逐步出现目标语言译文；上方齿轮打开设置，文档按钮「显示原文」移除全部译文，翻译过程中再次点击青色按钮可停止。普通网页保留原文与译文上下对照；需要「仅译文」显示时进入阅读模式。单段失败后可点击「重试失败段落」，成功段落不会重复请求；限流时先等待倒计时。鉴权、余额、限流或连接中断时会停止剩余任务，避免持续失败请求。

当前整页范围优先为唯一可见的 `article`，其次为唯一可见的 `main`；无法唯一识别正文区域时才处理 `body`，减少正文之外的导航、侧栏等请求。动态新增内容也只在当前选择的范围内采集。

代码块、代码编辑器、图片、输入框、可编辑区域、隐藏内容、标记不翻译的内容，以及判断为当前目标语言的正文会跳过。行内代码保留原始 DOM，并随所在段落提供字面值帮助翻译；不识别图片内文字。整页模式仅处理当前主文档，内嵌 iframe 保留原样。

只有主动点击才会把未命中页内缓存、符合当前语言设置的正文分批发送到所选服务。DeepL 优先发送当前可见正文，有可见正文时首批目标 800 字符、最多 2 项；不为首批软预算拆开完整段落。后续批次填充剩余容量，每四批让最早等待的内容先走一批。滚动只重排尚未发送的内容，正文范围内的标题和段落仍会全部处理。大模型 API 使用当前服务已保存的 Key 和模型，默认每批最多 16 个短段落、目标约 1,600 个字符，最多 32 路并发。每次最多 1,500 个段落，超长段落分块后按原序合并。开启整页翻译后，当前正文范围内动态追加且符合语言条件的内容也会继续翻译，直到停止或显示原文。不同服务的额度和限制可能不同，批处理不保证免费服务不再限流。

正文和译文只保存在当前文档内存，不持久化。纯文本缓存最多 1,500 项、约 2 MiB 文字预算；恢复原文会移除译文、取消请求并结束动态观察，保留这些缓存，再次点击时可复用仍在缓存中的同文译文。超出容量会淘汰旧项，未命中的文字仍需请求。导航、语言方向、连接配置或翻译方式变化、暂停/撤回网页权限、销毁时清空缓存，不跨文档复用。不同引擎的耗时分别验收，历史 DeepSeek 数据不代表 DeepL 速度。

在设置页点击「启用网页划词」，接受浏览器的 HTTP(S) 网页访问请求。该权限用于在选择文字后自动显示按钮。

刷新此前打开的网页，然后双击英文单词或拖选支持语种的句子/段落，松开鼠标后点击「译」。符合英语学习条件的模型单词卡显示词义、词性与语境解释，其余选区显示所选目标语言的普通译文。点击「复制」复制结果，点击 × 或按 Esc 关闭。

只有点击「译」才会发送选中文字和可选的有限上下文。新选区会取消旧请求；一次最多 12,000 字符，超出时请分段。关闭「启用翻译」会暂停网页和 PDF 的翻译，不影响 PDF 阅读。

浏览器设置页、扩展商店及其他受限页面不能显示按钮。iframe 需要对应网页权限。复杂网页组件的选择行为可能受网站本身影响。

## PDF 划词

在线 PDF：打开 PDF 标签页 → 点击近译图标 →「用阅读器打开当前 PDF」。地址不必以 `.pdf` 结尾。也可在阅读器的地址栏粘贴在线 PDF 链接，按「打开在线 PDF」。未授权的网站会请求访问权限。

本地 PDF：点击「选择本地 PDF / 输入 PDF 链接」→「打开本地 PDF」选择文件，无需授予所有本地文件访问权限。

在近译阅读器中双击单词或拖选句段，再点「译」。支持翻页、页码跳转、缩放、搜索和密码文件。整份 PDF 在阅读器中解析，不作为翻译请求上传到模型服务；仅发送所选文本和可选上下文。密码只保留于当前加载过程。

浏览器内置 PDF 阅读器禁止注入该浮层，因此必须进入近译阅读器。只有图片、没有文字层的扫描页会提示暂不支持 OCR；已有 OCR 文字层的文件可以选词。

需要登录、带临时 blob 地址或服务器拒绝下载的在线 PDF，可能无法直接加载。此时下载 PDF，再在近译中打开本地文件。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 新安装后不知道如何开始翻译 | 点击面板或设置页的「启用免费翻译」并授权；可另点「测试免费翻译」发送公开例句，启用不会自动翻译文章。 |
| 升级后仍在使用原模型 | 已有翻译方式与 Key 会保留；只有主动选择「启用免费翻译」或保存新的翻译方式才切换。 |
| 目标语言或英语学习功能不符合预期 | 在设置页检查源/目标语言并保存；词典限英语 → 简体/繁体中文，句法拆解限英语 → 简体中文，且均需模型模式。 |
| DeepL 显示冷却倒计时 | 保留已完成译文，等倒计时结束后手动重试；重开面板不会清零冷却，倒计时结束也不保证上游已恢复。 |
| 无法进入网页阅读 | 打开普通文章详情页并等待正文加载；用扩展面板「阅读当前网页」重试，扩展更新后刷新网页；PDF 使用 PDF 阅读器。 |
| 「仅译文」仍显示部分原文 | 该段尚无成功译文；切换模式不会自动翻译，配置服务后点击「翻译正文」，或重试失败段落。 |
| 没有「译」按钮 | 检查总开关、网页权限；授权或重载扩展后刷新网页；PDF 要在近译阅读器内打开。 |
| API Key 无效 | 核对当前服务、基址与 Key；修改地址后需重新填写 Key。 |
| 模型不存在或参数不支持 | 核对账户可用模型和 Chat Completions 兼容地址，接口不支持 JSON 模式时关闭。 |
| 本地接口无法连接 | 确认服务已启动、模型已安装，核对回环基址及 API 域名权限，检查服务自身的来源访问设置。 |
| 余额不足或请求过多 | 按卡片提示检查账户额度，稍后主动重试。 |
| 等待或网络失败 | 首连接超时 25 秒，整体最长 90 秒；检查网络后点击重试。 |
| 译文被截断 | 缩小选区后重试，保留更短的段落。 |
| 在线 PDF 无法打开 | 下载到本机，使用文件选择器打开。 |
| 扩展更新后连接中断 | 重新加载扩展并刷新网页；重新打开 PDF 阅读器。 |

## 从源码构建（开发者）

源码仓库不包含构建产物。使用 Node.js 24+、npm 11+，在项目根目录执行：

```sh
npm ci
npm run build        # Chrome
# Edge 用户改用：npm run build:edge
```

在扩展管理页开启「开发者模式」，点击「加载已解压的扩展程序」，Chrome 选择 `.output/chrome-mv3`，Edge 选择 `.output/edge-mv3`。

构建只更新对应的 `.output` 目录；若原安装加载的是别的目录，请按[已有用户升级](#已有用户升级)将程序文件更新到原加载位置，再重新加载扩展。更多开发约定见[贡献指南](../../CONTRIBUTING.md)。
