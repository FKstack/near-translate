# 近译 v0.11.16

改善篡改猴版 DeepL 整页翻译在长文上的等待：解除管理器同地址请求的串行等待，减少重复页面检查，并把新翻译占位的绘制安排到同一帧。本机真实长文样本从 v0.11.10 的 74.2293 秒缩短到本版约 15.3 秒；网络和上游负载未受控，不承诺每次相同速度。

- 继续免登录、无需 DeepL API Key，保留匿名请求、重定向拒绝、取消、超时和限流冷却。
- 模型 API 保持原有流式显示；现有设置和已保存的 API Key 继续使用。
- Chrome / Edge 扩展、PDF 阅读器和文档转换能力继续保留。

从原 GitHub 或 Greasy Fork 安装渠道更新，在篡改猴确认后刷新已经打开的文章页。无需重新填写配置。渠道入口与更新限制见[篡改猴指南](../guides/USERSCRIPT.md)；Greasy Fork 需在同步后才能取得新版，发布时须另核验公开版本。

## 真实测量与限制（发布前初稿）

当前同版本已测 Go 长文 251／251 段、53,505 UTF-16，零失败／待处理，首个初始可见正文 DOM 3.0665 秒、全文 **15.294699999988079 秒**。测试为实际安装的 v0.11.16、真实 DeepL、新冷文档、不复用脚本译文缓存、独立后台标签和有效 1280×900 视口；前台性能未测。原 15 秒研究目标未通过，用户明确接受当前观察速度后要求按流程发布。

本版另外四篇不同长度文章补测尚待完成，不能用 v0.11.15 的结果替代；同版本完整矩阵将在合并前补齐。免费服务仍可能因网络、限流或上游调整变慢或失败。完整方法、失败候选、速度接受来源及原数见[研究报告](../reports/USERSCRIPT_DEEPL_PERFORMANCE_2026-10-25.md)和[数字证据](../evidence/userscript-deepl-speed-2026-10-25.json)。

本地检查：原断言与 timeout 不变，2 workers 完整单测 1,566／1,566，两种脚本渠道浏览器回归各 22／22，类型、仓库、文档、模块边界以及 Chrome／Edge 和两渠道脚本构建通过。浏览器回归使用模拟 GM，不能替代上述真实服务测量；默认 64 worker 曾有一个原 5 秒 Git dry-run 超时，原阈值单项重跑通过，完整记录保留。PR/Linux CI、正式 Release、Pages 部署及 Greasy Fork 公开版本核验仍待工作流完成，本初稿不表示已经发行。
