# 近译 v0.11.8

API Key 填入保存后即可翻译。扩展版和篡改猴版都不再要求创建保护口令、逐页解锁或浏览器重启后解锁。

## 变化

- Key 保存在浏览器扩展或篡改猴的本机私有存储中，设置页不回显已保存的 Key，普通网页和公开消息不提供凭证读取入口。
- 扩展保存模型配置时一并申请必要权限，为已打开且已授权的普通网页补上翻译入口，无需另点启用或手动刷新。
- 旧版加密 Key 提供可选的一次性原口令导入，也可以直接重新填写；导入失败保留旧记录，已重新填写或删除的服务不会被旧导入覆盖。
- Key 继续按服务地址绑定；改变地址不会自动把旧 Key 发给新地址，远程模型接口仍要求 HTTPS，本机回环接口可用 HTTP。
- 更新设置页、安装说明、隐私说明和 Greasy Fork 简介，使保存方式与实际操作一致。

不再额外用用户口令加密 Key，私有存储隔离也不等于系统凭证保险箱。具体保护边界见[隐私说明](https://github.com/FKstack/near-translate/blob/v0.11.8/docs/guides/PRIVACY.md)。本次不新增翻译中转服务器或开发者数据收集，Chrome / Edge 的 PDF 阅读器与文档转换继续保留。

本地验证通过：1,451 项单元测试、61 项扩展浏览器场景、GitHub / Greasy Fork 脚本各 17 项浏览器测试，以及 Chrome / Edge 构建。模型调用使用假 Key 与模拟接口，未测试真实付费模型。
