# 紧凑、可移动的翻译浮栏

日期：2026-10-22；安装版本：0.8.0。

## 行为

- 默认仅显示40×40 px双叶按钮，副操作与提示不占网页点击区域。
- 鼠标悬停或键盘聚焦后展开阅读模式、原文和设置；离开后收起。Escape可主动收起。
- 去掉提示框154 px最小宽度；字号11 px，按内容决定宽度，最多176 px。提示可换行，长内容限高滚动，错误与重试仍可访问。
- 主按钮可拖动换位置，超过6 px才算拖动，不触发翻译；正常点击保留翻译/停止/恢复原文操作。Alt+方向键微调，Alt+Shift+方向键加快移动。
- 靠左时提示向右，靠下时工具向上；高度不超过240 px时工具横向展开。位置随窗口尺寸限制在可视内容区域，滚动条不挤出按钮。
- 状态计数、错误码、按钮可访问名称与`role=status`播报保留；闲置提示不常驻。失败/通知用小圆点提醒，展开后可读全文并重试。

## 架构

R2的局部UI交互修改：位置、拖动阈值与指针捕获均由PageBar组件持有，只有一个在途拖动；pointerup、pointercancel、lostpointercapture和卸载均清理捕获。唯一窗口resize监听随组件卸载移除。位置仅在当前组件内存中保留，不写浏览器存储。已有PageSession继续持有翻译，阅读回调保持原入口，无新权限、依赖、消息或持久化格式。

类型检查、模块边界、10项状态/mount单测、Chrome/Edge构建通过。真实React组件DOM验证包括折叠/展开、键盘、拖后点击、捕获取消、四角、缩窗、窄屏和短屏，截图为`compact-bar-idle.png`、`compact-bar-expanded.png`、`compact-bar-narrow.png`。

8项隔离Edge回归通过：DeepL整页恢复和429；主按钮重译与停止后恢复；失败段落重试；无Key阅读、已有译文复用、键盘阅读退出与过期结果。相关E2E次操作改为悬停展开后使用，语义选择器保持。

滚动条修正后，最终构建另复验主按钮与无Key阅读2项通过。强制17 px滚动条、滚动条出现/消失（不触发resize）和拖动后均保持8 px右间距；鼠标逐步经过6 px命中桥至重试按钮，提示保持展开且回调正常。
