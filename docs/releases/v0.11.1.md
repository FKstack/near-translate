# 近译 v0.11.1

这个版本为商店发布补齐了口令加密密钥库，并减少安装时的默认权限。商店发布状态以实际商店页面为准；下方 ZIP 仍可通过开发者模式安装。

## 下载安装

| 浏览器 | 安装包 | 扩展管理页 |
| --- | --- | --- |
| Chrome | [下载 Chrome 安装包](https://github.com/FKstack/near-translate/releases/download/v0.11.1/near-translate-chrome-v0.11.1.zip) | `chrome://extensions` |
| Edge | [下载 Edge 安装包](https://github.com/FKstack/near-translate/releases/download/v0.11.1/near-translate-edge-v0.11.1.zip) | `edge://extensions` |

1. 下载对应 ZIP，完整解压到长期保留的固定文件夹。
2. 打开扩展管理页，开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择直接包含 `manifest.json` 的文件夹，确认显示版本 **0.11.1**。
4. 固定近译到工具栏，打开普通文章，点击「阅读当前网页」即可先体验本地阅读。

请保留解压目录。ZIP 不能直接加载；GitHub 自动提供的 Source code 是源码，请下载上表中的安装包。附件 `INSTALL.md` 为本说明离线副本，`SHA256SUMS.txt` 可用于校验 ZIP。

## 这个版本的变化

- **API Key 用独立口令加密保存。** 在翻译设置中创建密钥库，浏览器重启后解锁；后台休眠不会要求重复输入口令。可以主动锁定或更换口令。
- **旧版 Key 安全迁移。** 设置口令后，先写入并验证密文，再清理旧明文。迁移失败会保留原始数据供恢复，不会悄悄删除。完成迁移前，旧明文 Key 不用于模型请求。
- **按需申请 API 权限。** 安装时不再默认获取 DeepSeek 主机权限，选择并保存服务时再授权对应域名。
- **锁定状态准确提示。** 锁定后停止模型请求；错误口令不能解锁。免费翻译和本地阅读不要求解锁模型密钥库。

密钥库使用 AES-256-GCM 和 PBKDF2-SHA-256；口令及明文解密钥匙不写入持久存储。解锁后的派生钥匙仅保留在受信任的浏览器会话内存。口令为12–128字符，空格属于口令，无法找回；遗失后无法解密已有 Key，请妥善保存，不要使用 API Key 作为口令。

## 第一次翻译

需要免费翻译时，在扩展面板点击「启用免费翻译」并授权，随后手动点击「翻译正文」或选区「译」。免费服务为实验性接入，可能限流。

需要模型语境词典或英语长句拆解时，在「翻译设置」选择「大模型 API」，先设置密钥库口令，再保存自己的服务、模型和 Key。模型用量由所选服务账户支付。点击翻译后，相应文字及可选上下文发送至该服务。

## 已有用户升级

先记录原扩展 ID、加载路径和非秘密设置，备份原程序目录。把新包程序文件更新到原加载目录，点击原扩展卡片的「重新加载」，确认版本和 ID，再刷新已打开的网页、重新打开 PDF 阅读器。

升级后到「翻译设置」为已有 Key 设置解锁口令，完成迁移后再使用模型。不要先移除旧扩展。更换路径、浏览器配置，或从手动版切换到不同身份的商店版时，设置不一定自动迁移。
