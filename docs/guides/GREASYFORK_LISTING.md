近译把网页双语翻译、划词和阅读模式放在同一个阅读过程里。

## 主要功能

- **网页双语翻译**：逐段显示译文，可以停止翻译或恢复原文。
- **划词翻译**：选择单词或句段后翻译。英语词典解释和长句拆解需要模型 API。
- **阅读模式**：本地提取正文，提供目录、阅读样式和原文／双语／译文切换。阅读本身无需 API Key。
- **自己的翻译服务**：支持兼容 OpenAI Chat Completions 的模型服务和本机接口。

## 开始使用

需要 **Tampermonkey 5.4 或更新版本**。点击本页的安装按钮，按管理器提示确认权限，再刷新文章页。从网页浮动入口或篡改猴菜单进入阅读；也可按 `Alt+Shift+R`。

从篡改猴的近译菜单打开[翻译设置](https://fkstack.github.io/near-translate/userscript/settings.html)。

实验性 DeepL 免费翻译无需 Key，但可能限流、调整或暂时不可用。使用模型 API 时，请填写自己的服务地址、模型名称和 Key；费用由对应服务决定。

## 数据与权限

只在主动翻译时，把正文、选中文字及可选上下文发送给选定的翻译服务。阅读模式在本机处理；文章中的图片可能仍从原网站加载。

模型 Key 使用独立口令加密，保存在篡改猴的脚本存储中。文章页通过篡改猴菜单解锁；解锁状态仅限当前页面，刷新后需重新解锁。原生口令提示框中的文字可见。普通 HTTP 页面可能不支持安全解锁；本地阅读与免费翻译仍可使用。

脚本匹配 HTTP(S) 顶层网页，跨域连接由篡改猴授权。自定义 API 使用 `@connect *`，请核对实际目标域名后授权。

安装和更新时，篡改猴会从 jsDelivr 下载固定版本、带 SHA-256 校验的 OpenCC 与 Mozilla Readability 库。业务代码在本脚本中提供，不从外部下载或执行近译的主程序。

本版不包含 PDF 阅读器和文档转换。同一网页请只启用一种近译安装方式，避免与扩展版重复运行。
