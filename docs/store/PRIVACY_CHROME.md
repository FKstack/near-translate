# 近译：Chrome 扩展隐私说明

适用于当前扩展源码，更新于 2026-10-25；旧版安装包请参阅对应 Release 标签下的说明。

近译帮助用户阅读、翻译和理解网页及 PDF，并在本机处理相关文档。无需创建近译账号，没有项目自有翻译中转服务器、广告或使用情况遥测。

## 处理哪些信息，为什么

| 数据 | 用途与去向 |
| --- | --- |
| 当前网页正文、所选文字及可选上下文 | 在本机提取和展示阅读内容；用户主动点击翻译时，仅将相应未缓存文字发往所选翻译服务。模型模式的额外上下文最多600字符。 |
| 当前页及用户提供的 PDF 地址 | 识别阅读来源、返回原文或从用户选择的来源获取在线 PDF；不建立、保存或上传跨网站浏览历史。在线 PDF 来源会收到正常下载请求。 |
| 用户主动填写的 API Key、模型名和接口地址 | 在本机保存服务配置；翻译时，Key 仅作为该服务的鉴权信息发送到相应接口。不会借用其他服务的 Key。 |
| 阅读样式、语言及功能开关 | 在本机扩展存储保存偏好，不使用浏览器同步存储。 |
| 用户选择的本地 PDF、图片和文档，以及 PDF 打开密码 | 在扩展页面内存中解析、阅读或转换；文件和密码不会整份上传给翻译服务。PDF 选文翻译遵循上述文字发送规则。 |

网页、文档或选区可能包含个人资料、私人通信、健康或财务内容；主动翻译此类文字时，它们同样会发往所选服务。请先检查内容及服务政策。

## 何时发生网络请求

本地阅读无需登录或 Key；点击「翻译正文」、选区「译」或手动重试时才发送相应正文。点击「测试免费翻译」仅发送界面展示的固定公开例句。英语句法拆解启用且符合条件时，会在句子翻译后向当前模型额外发送该句的分析请求。

实验性免费翻译直接连接 DeepL；模型翻译直接连接用户保存的接口。远程模型接口必须使用 HTTPS，仅本机回环服务允许 HTTP。使用网关时，该服务可能继续转发请求，数据留存、训练使用及费用以所选服务的政策为准。

用户可单独授权可选连接加速；启用且满足条件时，扩展可能在点击翻译前向固定 DeepL 地址发出不含正文、网页地址、Cookie 或 API Key 的连接准备请求。可以在设置中关闭。

阅读页面展示的图片可能从原图片网站加载；用户主动打开的链接会访问相应网站。外部服务和网站可能获得 IP 及正常网络元数据。PDF.js、字体与转换代码随包提供；本地文档转换不会自动加载文档中的外链图片。

## 保存、安全与删除

正文、译文、PDF、文档和密码仅在当前页面或请求内存中处理，不写入扩展持久存储。当前文档的有界译文缓存用于重复阅读，导航或相关配置、权限变化会清理。用户主动下载的转换结果保留在用户选择的目录。

API Key 及其绑定地址保存在浏览器扩展私有的本机存储中，访问限制为 `TRUSTED_CONTEXTS`，不使用浏览器同步存储。填入保存后即可翻译，换标签页、刷新或重启浏览器不需要解锁。Key 不额外使用用户口令加密；访问隔离不等于静态加密或系统凭证保险箱，拥有本机浏览器配置或受信任扩展运行环境访问权的人仍可能读取 Key。

旧版加密记录可选择用原口令导入一次，也可直接重新填写 Key。原口令只用于本地解密旧记录，不发往网络；失败时保留旧库，不覆盖已重新填写或已删除的服务。设置页不回显已保存的 Key，网页内容脚本和公开设置消息不提供凭证读取入口。

可在设置页删除对应服务已保存的 Key 后保存。卸载扩展可清除扩展保存的本机数据；关闭或离开页面可释放正文内存。已发送到外部服务的数据需要按该服务的政策及删除渠道处理，卸载本扩展不能撤回已发出的请求。

## 使用限制与联系

处理的数据仅用于用户选择的阅读、翻译、理解和本地文档功能。不出售数据，不用于广告、跨网站画像、信用评估或无关用途；不提供给完成用户所选功能之外的第三方。未集成远程分析或遥测。

隐私反馈：[项目 Issue](https://github.com/FKstack/near-translate/issues)。该渠道公开，请勿提供 Key、密码、私有文档或敏感个人信息。

更多实现与权限细节见[完整数据处理说明](../guides/PRIVACY.md)。
