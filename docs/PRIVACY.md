# 隐私与数据处理说明

适用于近译 0.7.0。扩展由浏览器本地运行，不需要近译账号，也没有项目自有的翻译中转服务器、统计或遥测服务。

## 发送到模型服务的内容

- 划词：点击「译」后发送选中文字；「附带上下文」开启时，额外发送所在句或邻近一句，最多 600 字符。
- 整页：点击翻译后将符合条件的英文标题、正文、列表和表格分批发送。启动后会继续处理动态新增内容，直到停止或显示原文。
- 长难句拆解：普通译文完成后，向当前模型额外发送一次所选句子的分析请求。关闭该功能可停止额外分析。

请求还包含翻译提示词、模型名和所需协议参数。配置了 API Key 时，Key 作为该 API 的鉴权凭证发送。数据直接发往你保存的 API Base URL；使用聚合服务或网关时，服务可能继续转发给上游模型。请按所选服务的隐私政策和账户协议判断数据留存、训练使用、计费及地区要求。选择 Ollama 预设并不自动保证所有数据只在本机，实际目的地由保存的基址和服务部署决定。

复制结果由用户主动触发并写入剪贴板。模型输出作为文本显示，不执行模型返回的 HTML 或脚本。

## 本机保存的内容

扩展在 `browser.storage.local` 保存开关、当前服务和每个服务的模型、基址、JSON 模式、Key。存储访问限制为 `TRUSTED_CONTEXTS`，内容脚本不能读取凭证；公开设置不包含 Key、API 基址或完整配置列表。受信任的设置页可读取不含 Key 的配置，Key 输入框不会回显已有凭证。

配置不使用浏览器同步存储。浏览器本机存储不是密码保险库，拥有本机、浏览器配置或调试权限的人仍可能访问数据。删除某服务的 Key 后保存，可清除该 profile 的 Key；卸载扩展可清除扩展本机存储。

原文、译文和整页同文缓存只保存在活动页面/请求内存中，不持久化到扩展存储。关闭或恢复原文会清理对应会话；页面本身的内容仍由访问的网站管理。

## PDF 与网络访问

本地 PDF 通过文件选择器读取，在扩展阅读器内解析。PDF 文件和密码不会作为翻译请求上传；模型只收到主动选中的文本与可选上下文。在线 PDF 需要从其来源网站下载，该网站仍会收到正常下载请求。PDF.js 的 worker、字体和解码资源随扩展打包，不从 CDN 动态加载。

为兼容原安装，DeepSeek 官方 API 域名保持必选访问权限。保存其他 API 配置时，扩展会申请该 API 域名的可选访问权限；HTTPS 为默认要求，仅本机回环地址可使用 HTTP。权限是浏览器域名权限，不只限于某个 URL 路径。

「启用网页划词」申请 HTTP(S) 网页访问权限，用于动态注入翻译栏和处理选区。获得权限本身不会启动翻译。暂停翻译或撤回网页权限会停止当前网页会话并移除未来注入；已发送的网络请求可能已由服务处理，取消不代表对方删除数据或免除费用。

## 反馈与开发

Issue、PR、截图和日志中请勿包含 API Key、私有文章、PDF、密码或完整浏览器配置。自动化测试使用隔离配置和模拟响应；历史真实 API 验证采用公开材料，不能据此推断其他服务的数据政策或真实连通性。
