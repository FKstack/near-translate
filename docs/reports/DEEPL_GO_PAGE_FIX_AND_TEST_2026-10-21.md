# Go 长文 DeepL 整页翻译：修复与真实验收

测试日期：2026-10-21，实际 Edge 155.0.4283.62、近译 0.7.0。

**结论：扩展侧性能修复已安装并通过自动化回归，但免登录 DeepL 对该长文的真实全文验收仍失败，不能标记为“已修好且全文快速完成”。**

目标网页：[Go at Google: Language Design in the Service of Software Engineering](https://go.dev/talks/2012/splash.article?utm_source=chatgpt.com)。全程使用 DeepL，没有切换为已有模型 API，没有读取或导出 Key、浏览器 Cookie。

## 原因与证据边界

1. **本地请求拆分过细。** 旧页面调度强制每批 1 项，provider 也逐项请求，并在每次结束后等 1 秒。页面提取 317 段；即使网络完全不耗时，数百次请求的固定等待也会累积到数分钟。这里是代码与文本数量分析，并非重新刷请求测得的旧版全文耗时。
2. **正文前有无关工作。** 旧采集从 body 开始，导航、促销等先于文章进入队列。此次页面的 article 有 251 段、53,505 个英文原文字符，已保留文章标题、目录、正文和文章内列表，没有缩短或摘要正文来制造速度数字。
3. **截图中的错误来自服务端限流。** 实际安装版本收到了 HTTP 429，并非只发生内容脚本异常或计时器卡住。改用批量、降低发送频率之后仍能复现，不能把“请求过快”认定为唯一原因，也不能推断固定请求配额、字符配额或 IP 封禁。服务端没有向本测试提供可据以确认具体阈值的公开契约。
4. **短文成功不代表长文可用。** 先前原版 OJBetter 链路与短段测试成功，只验证协议和对应输入。本轮真实向量资格测试的 16 项短标题、15 项约 4,189 字符正文、32 项约 2,588 字符混合输入均返回 200；随后长文连续请求仍限流。

## 已实施并安装的修改

- DeepL 页面调度改为每批最多 **32 项 / 4,800 字符**，整页保持一个在途批次。provider 实际使用 `params.texts` 数组，不再在批内逐项联网；请求体上限 64 KiB，备选译文为 0。
- 按本地 segment/part 索引回填。整批验证响应 ID、返回数量、每项非空文本后才发布；超长段保留分隔和 Unicode 边界，不接受缺项或错位结果，不自动拆单补发。
- 首次及动态扫描优先唯一可见 article，其次 main，最后 body。代码、图片、输入区和隐藏内容保护保留。
- 成功译文保存在当前文档的纯文本内存缓存，最多 1,500 项、约 2 MiB 文字预算。恢复原文释放节点与活动会话，保留缓存；导航、连接修订号、引擎变化及销毁清空。已有译文再次显示时无需重发；失败仍需手动重试。
- 最终保留更保守的**完成后至少 1,050 ms**全局间隔。首个请求不增加人为等待。429 立即停止队列并保存至少 60 秒的浏览器会话冷却，遵守更长的 Retry-After；无自动重试。这个参数没有消除此次服务端限制。
- 新增仅受信任扩展页可读的本地计数、时间与 HTTP 状态诊断，不记录正文或 Key，不上传遥测。测速根据结构化终态判断成功，避免把停止或部分完成算作全文成功。

模型 API 的默认 32 并发 / 16 项 / 1,600 字符调度保留。页面会话拥有采集和缓存，provider 拥有协议与全局队列，platform 拥有浏览器网络及本地诊断；架构影响 R2，无新增生产依赖或权限。

## 实际安装版本的两轮全文测试

两次均由新建公开网页、点击真实整页按钮开始，使用真实 DeepL 网络，没有模拟 fetch。测试之间原冷却已自然到期；没有清冷却、换 IP 或代理重试。

| 项目 | 第一轮批量方案 | 最终保守节奏方案 |
| --- | ---: | ---: |
| 每次完成后间隔 | 200 ms | 1,050 ms |
| 首屏正文出现 | 2.231 秒 | 2.329 秒 |
| 收到限流时耗时 | 10.507 秒 | 6.561 秒 |
| 已完成 / 文章总段数 | 125 / 251 | 59 / 251 |
| 实际网络请求 | 7 | 3 |
| HTTP 200 / 429 | 6 / 1 | 2 / 1 |
| 最大同时请求 | 1 | 1 |
| 全文通过 | **否** | **否** |

上表的 10.507 / 6.561 秒是失败停止时间，**不是全文完成时间**。第二轮比第一轮更早失败，进一步说明不能从一次成功请求数反推出稳定限额。发生 429 后已停止进一步真实网络测试。同页完整暖缓存的真实长文测速因冷轮未完成而未执行，不能声称已有真实暖缓存毫秒级成绩。

## 尚未满足的要求

这篇 53,505 字符文章的 **DeepL 免登录、整篇完成、快速且稳定**尚未通过。当前证据支持保留批处理、正文选择和缓存修复，但不支持继续将匿名 DeepL 当作长文快速整页翻译的可靠保证。服务端限流不是修改扩展即可消除的本地故障；需要可持续的服务访问通路后，才能再次验收全文耗时。

本轮没有自动切换到其他服务，没有把部分译文或旧版 DeepSeek 的成功耗时用作 DeepL 全文结果，也未完成全文人工翻译质量审校。
