# 近译 v0.11.6

Greasy Fork 介绍页现在提供完整的近译项目图文总览，帮助用户了解能力并选择合适的安装方式。

## 变化

- 增加双语阅读、语境词卡和扩展版 PDF 查词三张真实界面截图，注明预置示例内容与适用版本。
- 介绍网页双语、划词、长句拆解、阅读排版、PDF 阅读及本地文档工具，并用功能对照表明确篡改猴版与 Chrome / Edge 扩展版的范围。
- 补充项目主页、两种安装方式、模型服务、隐私权限和更新提示说明；扩展下载链接指向最新正式 Release。
- 将 PDF 展示图与现有截图一同部署到项目站点，供 Greasy Fork 介绍加载；说明源继续由仓库构建和同步，后续发行会保留图文内容。
- 将仓库的代理发布约定纳入版本控制，明确用户要求发布时应完成分支提交、CI、线性合并、Release、部署和 Greasy Fork 核验。

本次更新主要涉及介绍、展示资源和代理约定。原有扩展、脚本功能、设置保存及更新渠道继续保留，没有新增产品权限或翻译请求。

## 验证与升级

已核对 Markdown 链接及构建后的介绍和图片资源；正式发行沿用原有检查、两种脚本浏览器测试与公开分发文件校验。界面配图使用示例文章和预置响应，不代表真实模型服务的结果或可用性。

Greasy Fork 的脚本与介绍自动同步可能晚于 Pages 部署。已有用户保持原安装渠道，更新后刷新文章页即可；想自行确认每次升级时，请单独关闭管理器对近译的内建自动更新。
