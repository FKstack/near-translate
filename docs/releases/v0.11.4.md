# 近译 v0.11.4

这个版本首次将篡改猴功能分支合入 `main`，提供 GitHub 与 Greasy Fork 两种网页阅读版安装渠道，并加入使用时的新版提醒。Chrome / Edge 扩展继续保留，PDF 阅读器和文档转换仍由扩展提供。

## 变化

- 篡改猴版保留网页双语翻译、划词翻译和阅读模式，与本仓库共用对应功能模块。GitHub 安装包与 Greasy Fork 可阅读脚本分别构建。
- 主动翻译网页、划词、重试或进入阅读模式时，发现新版会弹出确认。取消后继续当前功能，下次主动使用再提醒；确定后打开原安装渠道，由篡改猴确认安装。
- 功能分支可以通过发布辅助命令提交、推送和创建 PR，检查通过后 squash 合并，使 `main` 保持线性历史。合并后自动创建 GitHub Release 和版本说明，再构建安装包并部署脚本同步源。
- Greasy Fork 沿用已配置的自动同步源；平台拉取时机可能晚于 GitHub Pages 部署，不保证即时完成。

## 安装与升级

篡改猴用户打开 [Greasy Fork 安装页](https://greasyfork.org/zh-CN/scripts/601973)，或使用原来的 [GitHub 分发安装页](https://fkstack.github.io/near-translate/userscript/)。保持原安装渠道，确认安装后刷新已打开的文章页。扩展版与篡改猴版的设置分别保存；同一网站只启用一种近译安装方式。

0.11.3 及更早版本没有新版提醒，需先从原渠道手动更新一次。**要每次升级都自己选择，请在篡改猴中单独关闭近译的内建自动更新。** 脚本确认框不能阻止管理器自行升级。版本检查每个渠道至多每天联网一次，缓存和 Greasy Fork 同步可能推迟提醒；取消不会永久忽略新版。

Chrome / Edge 用户继续使用本 Release 的对应 ZIP，并按[安装指南](https://github.com/FKstack/near-translate/blob/v0.11.4/docs/guides/INSTALL.md)更新原加载目录。不要先移除旧扩展；新开或刷新页面后使用新版。

## 验证范围

发布工作流检查仓库、文档、类型、单元测试与模块边界，构建两个扩展及两种脚本，并运行隔离浏览器中的网页、划词、阅读和设置测试。浏览器测试模拟 GM API 和翻译响应；它们不代表真实模型服务、个人篡改猴授权或 Greasy Fork 服务端同步已经实测。

GitHub Release 创建后仍需等待构建和部署完成；Greasy Fork 的实际版本以公开页面和安装脚本为准。用户配置的模型服务可能计费，模型 Key 不随发布或同步上传。
