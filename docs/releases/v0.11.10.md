# 近译 v0.11.10

修复篡改猴版 DeepL 免费翻译一直等待、没有译文，最终提示超时或连接失败的问题。

- DeepL 改为读取完整 JSON 文本，避免篡改猴已经返回 HTTP 200 后响应流仍不结束，导致译文无法交付。
- 模型 API 继续流式显示译文；取消、超时、重定向保护、响应大小限制及 DeepL 限流冷却继续生效。
- Chrome / Edge 扩展、PDF 阅读器和文档转换能力保留。

从原安装渠道更新到此版本，再刷新已经打开的文章页。已有配置和 API Key 继续使用，无需重新填写。

使用原封 Tampermonkey 5.4.1 和独立测试浏览器复现并验证修复：同一完整 JSON 在流式模式下卡住，在完整文本模式下正确完成。实际安装的旧脚本在公开 Go 文章复现了 0/251 段、90 秒等待超时。详细元数据见[验证记录](../evidence/userscript-deepl-json-2026-10-25.json)。免费服务仍可能受到网络、限流或上游服务调整影响。

本地检查通过：1,480 项单元测试、两个脚本渠道各 22 个浏览器场景、类型检查、模块边界检查、仓库与文档检查，以及 Chrome / Edge 和两渠道脚本构建。浏览器回归使用模拟服务；上面的真实篡改猴对照直接使用本机固定 JSON 服务。
