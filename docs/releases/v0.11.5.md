# 近译 v0.11.5

GitHub Pages 现在有独立的[项目介绍首页](https://fkstack.github.io/near-translate/)，帮助第一次访问的人了解阅读体验并选择安装方式。

## 变化

- 沿用双叶标志、暖白纸面、深绿文字和青绿操作色，提供适配桌面与手机的项目介绍。
- 使用现有真实界面截图，介绍网页双语、语境查词、阅读排版、PDF 与本地文档工具；截图旁注明预置示例内容。
- 在相应功能和安装入口旁说明模型要求、DeepL 实验性限制、PDF 选文范围及扩展版／篡改猴版差异。
- 首页分开提供 Chrome／Edge 扩展和篡改猴安装入口，并补充服务选择、隐私说明和常见问题。

原有 `/userscript/` 安装、设置、指南、脚本与更新地址，以及 `/greasyfork/` 同步源继续保留。已有用户无需更换安装渠道。本次没有新增账号、数据统计、翻译中转或产品权限。

## 验证与边界

首页使用静态 HTML、CSS 和仓库内图片，没有运行时 JavaScript 或外部字体。已在隔离浏览器检查 360、390、768、1024、1440 px 的布局、站内资源、图片、锚点、FAQ 和键盘操作。完整发布仍由原有工作流构建并验证各分发渠道。

发布工作流成功前，GitHub Release 的出现不代表 Pages 部署已完成。Greasy Fork 拉取同步源也可能晚于 Pages 部署；各渠道实际版本应分别核验。
