# 证据目录

本目录保存各次研究与验收的 JSON 摘要、哈希、截图和静态分析说明。相关结论、运行条件和失败轮次见 [历史报告](../reports/)；[验证记录](../development/VALIDATION.md) 汇总各阶段检查范围。

文件名日期一般沿用任务开始日期，JSON 内时间可能使用 UTC。版本号、测试数量、安装路径和文件哈希属于该次测量时点，不能当作当前发布版本的保证。部分历史元数据包含本机工作区或安装目录名称；它们用于解释测量来源，不是安装要求。整理目录时未改写历史 JSON 的内容。

阅读测量时请区分：

- 隔离浏览器与模拟翻译服务的回归检查，验证交互和协议处理；它们不证明真实服务延迟或翻译质量。
- 日常浏览器中明确标注的真实服务结果，只支持该版本、网页、网络与测试时段，包含的失败记录同样需要保留。
- JavaScript 堆、浏览器进程内存、PDF worker、位图与 GPU 内存属于不同口径。内存审计中 GC 后的堆对照不能等同于任务管理器总内存。
- 解压安装体积、ZIP 大小、源码候选大小与运行内存分别报告，不能互相替代。

原始浏览器配置、下载产物、临时诊断脚本和大量重复运行输出通常位于本机 `.output/` 或 `artifacts/`，不会上传。本目录中已有的摘要与截图保留；报告对未归档的本机文件仅注明历史路径，避免产生干净克隆中的断链。新增测量默认写入 `.output/`，需要公开引用时再审阅并选择性归档，避免混入凭证、浏览器资料或用户正文。
