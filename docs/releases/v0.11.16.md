# 近译 v0.11.16

改善篡改猴版 DeepL 整页翻译在长文上的等待：解除管理器同地址请求的串行等待，减少重复页面检查，并把新翻译占位的绘制安排到同一帧。本机真实长文样本从 v0.11.10 的 74.2293 秒缩短到本版约 15.3 秒；网络和上游负载未受控，不承诺每次相同速度。

- 继续免登录、无需 DeepL API Key，保留匿名请求、重定向拒绝、取消、超时和限流冷却。
- 模型 API 保持原有流式显示；现有设置和已保存的 API Key 继续使用。
- Chrome / Edge 扩展、PDF 阅读器和文档转换能力继续保留。

从原 GitHub 或 Greasy Fork 安装渠道更新，在篡改猴确认后刷新已经打开的文章页。无需重新填写配置。渠道入口与更新限制见[篡改猴指南](../guides/USERSCRIPT.md)；Greasy Fork 需在同步后才能取得新版，公开版本由发布工作流另行核验。

## 同版本真实验证与限制

实际安装的同一 v0.11.16，在真实 DeepL、新冷文档、不复用脚本译文缓存、独立后台标签、有效 1280×900 视口下完成五篇：

| 文章 | 原文 UTF-16／段数 | 全文耗时 | 完成／失败／待处理 |
| --- | --- | ---: | --- |
| Rust 1.85.1 | 1,352／17 | 3.0783 秒 | 17／0／0 |
| Go：Errors are values | 6,797／35 | 3.8256 秒 | 35／0／0 |
| Python 3.14 | 4,428／96 | 3.3855 秒 | 96／0／0 |
| Rust 1.85.0 | 7,869／66 | 3.6378 秒 | 66／0／0 |
| Go SPLASH 长文 | 53,505／251 | 15.2947 秒 | 251／0／0 |

五篇均无原文变化、映射冲突或受保护代码区域译文。长文首个初始可见正文 DOM 为 3.0665 秒，全文为 15.2947 秒（约 15.3 秒）；原 15 秒研究目标未通过，用户明确接受当前约 15.3 秒后要求发布，不能写成原目标达标。前台性能未测，Python 初始首屏无合格正文目标的时钟保留为空。免费服务仍可能因网络、限流或上游调整变慢或失败；本轮成功不构成稳定速度保证。全部原数、历史失败、Rust 宿主版本元数据更正来源见[研究报告](../reports/USERSCRIPT_DEEPL_PERFORMANCE_2026-10-25.md)和[数字证据](../evidence/userscript-deepl-speed-2026-10-25.json)。

本地检查：原断言与 timeout 不变，2 workers 完整单测 1,566／1,566，两种脚本渠道浏览器回归各 22／22，类型、仓库、文档、模块边界以及 Chrome／Edge 和两渠道脚本构建通过。浏览器回归使用模拟 GM，不能替代上述真实服务测量；默认 64 worker 曾有一个原 5 秒 Git dry-run 超时，原阈值单项重跑通过，完整记录保留。本记录完成时最终证据提交的 PR CI、合并、Release、Pages 和 Greasy Fork 公开版本核验仍待工作流完成，产品验证通过不表示已经公开发行。
