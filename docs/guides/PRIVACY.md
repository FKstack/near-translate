# 隐私与数据处理说明

适用于近译 0.11.2，更新于 2026-10-24。扩展由浏览器本地运行，不需要近译账号，没有项目自有的翻译中转服务器，也不上传统计或遥测。本地处理也属于数据处理；这不表示扩展不读取网页内容或不处理用户主动提供的 API Key。

## 数据用途与联系

近译仅为用户选择的网页和文档阅读、翻译、理解及本地文档操作处理数据。不会出售用户数据，不用于广告、建立跨网站用户画像、信用评估或与这些功能无关的用途。只有完成用户请求所需的文字、可选上下文和必要鉴权信息会发送到用户选择的翻译服务；不把 API Key 发送给其他服务。下文另行说明用户可选启用的无正文连接准备。

网页或文档正文可能包含姓名、私人通信、健康或财务等内容。扩展不会专门搜集这些类别；如果用户主动选择翻译包含此类信息的文字，该文字仍会按相同规则发送到所选服务。请在翻译前检查内容及服务的数据政策。外部请求的接收方仍可能获得 IP 地址和正常网络元数据，具体处理由该网站或服务的政策决定。

隐私问题可通过[项目 Issue](https://github.com/FKstack/near-translate/issues)联系维护者。Issue 为公开渠道，请不要填写 Key、密码、私有文档或个人敏感信息。可在设置页删除相应服务已保存的 Key 后保存；卸载扩展可清除扩展的本机保存数据。关闭或导航离开页面可释放正文与译文内存。已发送到外部服务的数据需要按该服务的政策及删除渠道处理，卸载近译不代表对方已经删除。

## 本地文档转换

「文档转换」中的文档、图片、PDF 和打开密码仅在该扩展页面本地处理，不上传文件，不调用翻译服务，不读取或保存 API Key。PDF.js、字体映射、Marked 与 pdf-lib 均随扩展分发，不使用远程转换接口。Markdown / HTML 中的外链图片不会自动加载；只有用户附加的本地位图可内嵌到结果。用户主动点击的外部超链接会正常打开相应网站。

文件、密码和临时下载链接不持久化，关闭转换页后清除内存状态；用户主动保存的 PDF、HTML、文字或 ZIP 留在所选下载目录。Markdown / 文本 / HTML 点击“下载 PDF”后直接在本机生成 PDF 并发起下载，不经过打印窗口；所需字体随扩展分发，按需子集嵌入，不联系远程字体服务。可选下载的 HTML 包含所附图片。此功能与 PDF 选文翻译独立，只有用户另行使用翻译功能时才适用下文的翻译数据规则。

## 首次启用、语言与公开例句

全新安装且没有已有设置时，默认翻译方式为 DeepL 免费翻译，默认语言为自动识别到简体中文；这不代表自动授权、自动试译或自动上传文章。升级保留已有翻译方式、模型配置和各服务 Key，只有用户主动切换才改变引擎。启用免费翻译或更改语言不会删除模型配置，也不会把模型 Key 发送给 DeepL。

面板和设置页的「启用免费翻译」一次申请 HTTP(S) 网页访问及 `https://oneshot-free.www.deepl.com/*` 服务域名权限；拒绝授权不修改原配置。得到权限后仍需点击正文翻译或选区「译」才发送相应内容。独立的可选连接加速若先前已获授权，仍可能进行下文说明的不含正文的连接准备；普通翻译不依赖它。

「测试免费翻译」是独立、明确的用户操作。只有点击该按钮时，后台才发送固定公开英文 `The library opens at nine in the morning.`，固定由英语译为简体中文；不读取当前文章、选区、PDF 或网页地址作为试译内容，不使用模型 Key。它不改变用户保存的语言方向。打开面板、保存设置、读取服务状态或只点击「启用免费翻译」均不会自动发送该例句。界面展示的译文和耗时仅代表本次连接，不构成服务可用性或速度保证。

源语言可选自动识别或 16 个语言选项，目标语言可选同样 16 项：简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、俄语、葡萄牙语、意大利语、阿拉伯语、印地语、印尼语、土耳其语、越南语。网页、阅读层和 PDF 选文共用语言设置，请求携带完成翻译所需的语言参数或提示词。模型词典仅面向英语到简体/繁体中文，句法拆解仅面向英语到简体中文；其他方向发送普通文本翻译请求，DeepL 不额外请求这两类模型分析。

DeepL 的中文输出在完整段落合并后使用随包的 OpenCC 字典于本地规范简体或繁体字形，不发起第二次请求、不下载远程字典，也不修改或保存源网页文字。它只处理目标字形，不替代人工译审或改变服务端翻译含义。

## 网页阅读模式

通过网页侧栏「阅读模式」、扩展面板「阅读当前网页」或 `Alt+Shift+R` 进入时，正文在当前浏览器本地提取；无需登录、API Key 或可用的翻译服务。提取基于已经加载的页面快照，不上传正文。安全白名单逐节点重建阅读内容，排除原站脚本、事件属性、表单和嵌入对象，不执行 Readability 或翻译结果中的 HTML 字符串。

本地提取不代表整个浏览器零网络：阅读界面展示的图片可能从原图片站点加载，外链在用户点击后导航；原网站自身仍可能有正常网络活动。图片只接受校验后的 HTTP/HTTPS 地址，使用 `no-referrer`；提取阶段不为图片设置活动 `src`。已有可选 DeepL 连接准备的无正文行为保持，详见下节。

「原文」「双语」「仅译文」切换、目录跳转及显示设置不自动发起正文翻译。点击「翻译正文」或主动划词翻译后，只把相应未命中页内缓存的内容按既有流程发给当前引擎；重试同样需要用户操作。阅读层没有独立中转或新的 DeepL 协议，继续共用后台 provider、请求预算和 429 冷却。未完成段落保留原文，停止不撤销服务已经收到的内容。

阅读文章 DOM、源节点映射、选区文字快照和滚动测量索引只在当前文档内存中存在。关闭时取消阅读翻译，释放文章 DOM、原节点映射、监听与待执行测量，恢复原网页滚动和仍有效的焦点；普通关闭可在当前文档内保留有界纯文本成功缓存及位置标识供重开。导航、连接/翻译方式或权限变化、销毁会清理相应缓存，不保存跨页正文、阅读位置或浏览历史。

无正文的显示偏好写入独立的 `reading-preferences:v1`：主题、字号、行距、栏宽、字族、显示模式、段落专注，以及 0.10.0 新增的有界间距/对齐/代码折行/译文样式、自定义三色和单个个人外观快照。旧七字段数据读取时补默认。规范化丢弃正文、HTML、URL、API Key 等其他字段；个人外观不能递归、不含显示模式或文章。不读取或改写 `settings:v1` 中的模型配置。用户可显式导入/导出本地版式 JSON，仅搬迁当前外观；不上传文件，未知格式、超限或非法字段不覆盖当前设置，未知额外字段被丢弃。没有新增远程字体、云端同步或服务请求。后台验证同扩展 id，并仅向自身受信任扩展页或 HTTP(S) 顶层内容脚本提供规范化的偏好；本地存储仍限制为 `TRUSTED_CONTEXTS`。偏好写入串行，读取等待已排队写入，不使用浏览器同步存储。设计与资源边界见[阅读模式记录](../reports/READING_MODE_DESIGN_AND_VALIDATION_2026-10-22.md)和[自定义设计](../reports/READING_CUSTOMIZATION_DESIGN_2026-10-23.md)。

## DeepL 免费翻译

选择该模式后，点击翻译才将选中文字或符合条件、未命中页内缓存的网页正文直接发送到 `https://oneshot-free.www.deepl.com/v1/translate`；主动点击公开例句测试时发送上节的固定文字。body 包含字符串数组 `text` 和所选目标语言 `target_lang`，默认值为 `zh-Hans`；源语言为自动识别时省略 `source_lang`，明确选择时发送相应代码，简繁中文来源均映射为 `zh`。不读取浏览器 Cookie，不要求登录、API Key 或 OAuth Token，请求使用 `credentials: omit`；`Authorization: None` 是匿名哨兵，不是 Key 或登录凭证。不附带额外选区上下文，不请求词典或句法分析。DeepL 对收到内容的处理仍取决于其服务政策。

同一次输入的文本按每请求最多 32 项、合计 1,500 个 UTF-16 单元分批，请求体最多 64 KiB，响应最多 1,000,000 字节。所有调用共享最多 8 个在途请求，相邻执行启动至少间隔 100 ms，滚动 12 秒最多启动 30 次；这是客户端保护策略，不是 DeepL 官方额度。自然遇到 429 后停止排队、取消其他在途请求，保留已完成译文并显示冷却倒计时，至少 60 秒，服务要求更长等待时沿用更长时间。不自动重试、不自动改用模型服务；到期只恢复手动操作入口，仍需用户点击继续或重试。倒计时不表示服务端一定恢复，也不代表 429 已解决或有速度保证。取消不代表服务端尚未收到或处理已经发出的文字。

倒计时来自本地可信浏览器会话中保存的冷却截止时间。读取或刷新服务状态仅在扩展内部通信并恢复本地记录，不向 DeepL 发送状态轮询或试译，也不消耗翻译启动预算。关闭再打开面板、后台休眠或切换引擎不会清零同一浏览器会话中的 DeepL 冷却；模型模式本身不使用 DeepL 的冷却时间。

第五轮的通用尾部装包改进，使该Go网页从38次请求减少至37次，仍免登录、无需API Key。实际Edge全新标签页、无扩展译文缓存的一轮完成251段/53,505字符，37次HTTP200；首段正文1.420秒、初始4段1.863秒、全文14.295秒，导航到全文19.664秒。但同版本约94秒后再开新标签页，在第21请求429，仅完成118段。**全文10秒未达，429尚未可靠解决，不能把成功单轮当稳定保证。** 当前保留原8路/100ms/30次每12秒保护及已回归的装包改进；更激进候选均已撤下。研究、所有失败轮和限定结论见 [第五轮报告](../reports/DEEPL_PERFORMANCE_V5_2026-10-22.md)。 先前18秒与14.8秒的窗口结果保留在 [第二轮](../reports/DEEPL_PERFORMANCE_V2_2026-10-22.md) 和 [第三轮](../reports/DEEPL_PERFORMANCE_V3_2026-10-22.md)。旧缓存重译不是新标签速度；上游缓存、负载和网络不受控，不保证长期相同耗时。可选元数据连接准备沿用第四轮；本轮未更改匿名正文预算、账号身份或模型Key。

在普通设置表单保存此模式只申请 `https://oneshot-free.www.deepl.com/*` 的域名权限；上节的「启用免费翻译」同时申请网页权限。普通翻译无需DNR，不使用webRequest，不伪造Origin/Referer、官方客户端或设备身份，不发送app_information，也不使用已有模型Key。旧会话规则74001仍尽力清理。

DeepL 整页调度在当前文档内测量原文节点的可视位置，优先处理可见正文；有可见正文时首批软目标为 800 字符、最多 2 项，后续填充批次剩余容量，每四批优先处理最早等待的内容。滚动只改变未发送任务的顺序，不减少已选正文范围，也不上传可视位置或滚动轨迹。调度与诊断未增加权限或运行时依赖。

可选连接加速使用已声明的 `declarativeNetRequestWithHostAccess` 权限；设置页可以启用或关闭，历史已有该权限时显示为已启用。只有DeepL及网页/服务权限均开启时，顶层可见HTTP(S)非PDF文档在document_start发送不含正文/URL的准备消息。后台固定OPTIONS请求不含Cookie、API Key、正文或Referrer；规则74002只给自身固定地址OPTIONS加两个标准ACR协商头，不修改Origin、UA、POST或响应。准备可能在未点击时联系DeepL，正文仍只在点击后发送。所有标签共享至少30秒的准备调度预留间隔（不等于实际HTTP间隔），trusted session时间戳跨worker重启保留；5秒总期限含排队，取消及429复用共享调度器，普通POST不依赖此能力。没有新增必需权限或依赖包。

## 发送到模型服务的内容

- 阅读模式：点击「翻译正文」后，将阅读快照中符合条件且未命中缓存的正文发送给当前服务；不发送整份 HTML、源节点映射、滚动轨迹或阅读位置。选择原文/双语/仅译文本身不触发请求。
- 划词：点击「译」后发送选中文字；「附带上下文」开启时，额外发送所在句或邻近一句，最多 600 字符。
- 整页：点击翻译后将符合当前语言设置、未命中页内缓存的标题、正文、列表和表格分批发送。范围优先为唯一可见 article，其次为唯一可见 main，否则回退 body；启动后会继续处理该范围内符合语言条件的动态新增内容，直到停止或显示原文。
- 长难句拆解：模型模式、英语到简体中文方向且符合单句条件时，在普通译文完成后向当前模型额外发送一次所选句子的分析请求。关闭该功能可停止额外分析。

请求还包含翻译提示词、模型名和所需协议参数。配置了 API Key 时，Key 作为该 API 的鉴权凭证发送。数据直接发往你保存的 API Base URL；使用聚合服务或网关时，服务可能继续转发给上游模型。请按所选服务的隐私政策和账户协议判断数据留存、训练使用、计费及地区要求。选择 Ollama 预设并不自动保证所有数据只在本机，实际目的地由保存的基址和服务部署决定。

复制结果由用户主动触发并写入剪贴板。模型输出作为文本显示，不执行模型返回的 HTML 或脚本。

## 本机保存的内容

扩展在 `browser.storage.local` 保存开关、当前服务、源/目标语言和每个服务的模型、基址、JSON 模式等非秘密配置。0.11.1 新增口令加密密钥库：API Key 及其绑定服务地址使用 AES-256-GCM 加密保存；解锁口令经 PBKDF2-SHA-256（600,000 次迭代、随机盐）派生密钥，每次写入使用新的随机 IV。解锁口令和明文解密钥匙不写入本机持久存储，不发送到网络。

解锁后，派生钥匙只在受信任的 `storage.session` 浏览器会话内存中保留，以跨后台休眠继续使用；浏览器重启后需要再次解锁。手动锁定可清除该会话钥匙。存储访问限制为 `TRUSTED_CONTEXTS`，网页内容脚本不能读取凭证。公开设置仅提供语言及密钥是否可用／锁定等能力布尔，不包含 Key、口令、密文、API 基址或完整配置列表。受信任的设置页也不回显已保存的 Key。

从旧版本升级时，已有明文 Key 等待用户设置解锁口令迁移。迁移完成前不把这些旧 Key 提供给模型请求；只有密文写入并验证成功后才清理旧配置中的明文。迁移失败不会为隐藏错误而删除原始凭证；请完成设置页提示的迁移后再使用模型。切换到免费翻译仍保留模型配置及密钥库；它不要求解锁模型密钥库。

0.8.0 另在独立键保存上述无正文阅读偏好；正文、译文、源节点映射和阅读位置不因此写入本地存储。网页阅读入口可使用既有 `activeTab` 只向当前标签页注入，翻译与自动网页划词仍受原来的开关及权限约束。

配置不使用浏览器同步存储。口令加密不能保护已解锁浏览器中被恶意程序、调试工具或受信任扩展页面自身攻陷的运行内存；请使用独立的长口令，不要使用 API Key 作为口令。口令不能找回，遗忘后无法解密已有 Key，请保留自己所用服务的凭证恢复渠道。删除某服务的 Key 后保存，可清除密钥库中该服务的 Key；卸载扩展可清除扩展本机存储。

原文、译文和整页同文缓存只保存在当前文档/请求内存中，不持久化到扩展存储。整页缓存包含原文与译文的纯文本，最多 1,500 项；按两者 UTF-16 长度乘 2 估算的文字预算最多 2 MiB，该预算不代表全部 JavaScript 对象或 DOM 的内存开销。缓存不持有 DOM 节点引用，超出容量按最近使用顺序淘汰。

恢复原文会取消请求、清理译文节点与活动会话，保留当前文档的纯文本缓存，以便主动再次翻译时复用。导航、源/目标语言、连接修订号或翻译方式变化、暂停/撤回网页权限和销毁会清空缓存，不跨文档、语言方向或连接复用。页面本身的内容仍由访问的网站管理。

DeepL 限流时，仅将冷却截止时间保存到可信的浏览器会话存储，以跨后台休眠保留等待时间；不保存原文、译文或账号信息。浏览器会话结束后此临时记录清除。

启动窗口另在当前后台实例内存中最多保存 30 个数字启动时间戳，不含正文或账号信息，不写入浏览器存储。已经启动的任务即使取消或失败也不退还计数，空闲和 429 不清空历史；记录按时间自然过期，调度器销毁时清理。通用调度器未配置窗口时保留原来的并发与间隔行为。

DeepL transport 在后台内存中另保留无正文的本地诊断：请求数、文本项数、字数、并发计数、HTTP 状态或安全错误码、fetch 起止时间，以及最近最多 256 次请求的这些指标。浏览器提供可用的 Resource Timing 时，可附带本扩展固定翻译地址的 DNS、连接、TLS、等待、下载与总耗时，以及限定的协议名称；缺失时省略，不将零值推断为冷连接或热连接。该读取不产生额外网络请求，也不采集其他标签页的网络记录。

429诊断最多在内存中读取8KiB错误体、等待1秒，最多保留64条，只保存可选安全整数错误码、5种固定reason类别、支持格式的RateLimit数字、等待时间和读取结果。分类是粗线索，不是已查明的服务端流控维度。不保留原始错误字符串、正文、Key或Cookie，不持久化或上传遥测；仅受信任扩展页面可读。连接准备另有最多64行纯数字计数/状态/时序，独立于正文POST；后台销毁时这些诊断丢弃。

## PDF 与网络访问

本地 PDF 通过文件选择器读取，在扩展阅读器内解析。PDF 文件和密码不会作为翻译请求上传；翻译服务只收到主动选中的文本，以及模型模式下的可选上下文。在线 PDF 需要从其来源网站下载，该网站仍会收到正常下载请求。PDF.js 的 worker、字体和解码资源随扩展打包，不从 CDN 动态加载。

0.11.1 不再声明必选 API 主机访问权限。包括 DeepSeek 在内，保存模型配置时按需申请该 API 域名的可选访问权限；HTTPS 为默认要求，仅本机回环地址可使用 HTTP。权限是浏览器域名权限，不只限于某个 URL 路径。

「启用网页划词」申请 HTTP(S) 网页访问权限，用于动态注入翻译栏和处理选区。获得权限本身不会启动翻译。暂停翻译或撤回网页权限会停止当前网页会话并移除未来注入；已发送的网络请求可能已由服务处理，取消不代表对方删除数据或免除费用。
