# 近译 v0.11.0

读外文，留在文章里。这个版本提供 Chrome / Edge 安装包，下载后解压加载即可使用，无需安装 Node.js 或编译源码。

## 下载安装

| 浏览器 | 安装包 | 扩展管理页 |
| --- | --- | --- |
| Chrome | [下载 Chrome 安装包](https://github.com/FKstack/near-translate/releases/download/v0.11.0/near-translate-chrome-v0.11.0.zip) | `chrome://extensions` |
| Edge | [下载 Edge 安装包](https://github.com/FKstack/near-translate/releases/download/v0.11.0/near-translate-edge-v0.11.0.zip) | `edge://extensions` |

1. 下载对应 ZIP，将全部内容解压到长期保留的固定文件夹。
2. 在浏览器地址栏打开上表中的扩展管理页，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**。
4. 确认「近译 · 阅读与翻译」版本为 **0.11.0**，通过扩展菜单将近译固定到工具栏。
5. 打开一篇普通文章，点击近译图标 →「阅读当前网页」。

请保留解压后的文件夹。ZIP 不能直接加载，GitHub 自动附带的 **Source code (zip / tar.gz)** 是源码，请选择上表的安装包。目前通过开发者模式安装，尚未提供浏览器商店安装。

## 第一次使用

- **先阅读**：本地阅读无需登录或 API Key；「显示设置」可以调整主题、字号、行距、栏宽，并保存个人样式。
- **再翻译**：点击「启用免费翻译」并按浏览器提示授权，随后手动点击「翻译正文」或选中文字后点击「译」。DeepL 免费服务为实验性接入，可能限流。
- **使用模型**：在「翻译设置」切换「大模型 API」，配置自己使用的服务、模型与 Key。英语语境词典和长句拆解需要模型模式；API 费用由所选服务账户承担。
- **读 PDF**：通过扩展面板选择本地 PDF 或输入 PDF 链接，在近译阅读器中选中文字翻译。扫描件需要已有 OCR 文字层。

需要翻译时，相应文本及可选上下文会发送至你选择的服务。文档转换在本机完成。详细配置、支持范围及常见问题见[安装与使用指南](https://github.com/FKstack/near-translate/blob/v0.11.0/docs/guides/INSTALL.md)，数据说明见[隐私说明](https://github.com/FKstack/near-translate/blob/v0.11.0/docs/guides/PRIVACY.md)。

## 这个版本可以做什么

- 网页双语与划词翻译；模型模式提供英语语境释义和长句拆解。
- 专注阅读模式，支持原文、双语、仅译文，以及主题、排版预设、个人样式和版式导入导出。
- 固定在阅读顶部的翻译入口，翻译过程中可以停止，失败后手动重试。
- 本地或在线 PDF 阅读、选文翻译，以及 Markdown / HTML / 文本到 PDF、PDF 合并拆分等本地文档工具。
- 按需加载 PDF 与文档转换资源，保留依赖和字体许可证。

## 已有用户升级

先记录原扩展的 ID、加载路径和翻译设置，并备份原程序目录。将新包完整解压后，更新到**原来加载的同一路径**，再点击原扩展卡片的「重新加载」；确认版本和 ID，刷新已打开的网页，重新打开 PDF 阅读器。不要先移除原扩展。

阅读模式中的「导出版式」可以备份当前显示偏好，不包含 API Key 或翻译服务配置。更换加载路径、浏览器配置或卸载重装时，不能保证原设置自动迁移。[完整升级步骤](https://github.com/FKstack/near-translate/blob/v0.11.0/docs/guides/INSTALL.md#已有用户升级)。

## 校验文件

附件 [SHA256SUMS.txt](https://github.com/FKstack/near-translate/releases/download/v0.11.0/SHA256SUMS.txt) 提供两个安装包的 SHA-256。Windows 用户可在下载目录运行：

```powershell
Get-FileHash .\near-translate-chrome-v0.11.0.zip -Algorithm SHA256
# Edge 用户改为 near-translate-edge-v0.11.0.zip
```

将结果与校验文件中对应包名的值比较。附件 `INSTALL.md` 提供本页说明的离线副本。
