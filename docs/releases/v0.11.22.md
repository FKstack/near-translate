# 近译 v0.11.22

## 官网焕新

- 首页采用与双叶图标一致的深青与薄荷绿，保留象牙色阅读面板，以「Read on. / 读下去。」呈现近译的阅读理念。
- 新增可切换的词、句、篇阅读示例，并通过真实阅读模式与 PDF 界面展示产品能力。
- 统一按钮曲线和交互层级，精简首页说明，保留扩展、脚本、指南、设置与隐私入口。
- 适配电脑、平板和手机，支持键盘操作与减少动态效果的系统偏好。

## 使用与升级

访问 [近译官网](https://fkstack.github.io/near-translate/) 即可看到新版首页，无需更改已有设置。扩展与脚本继续沿用原有安装和更新渠道。

本次改动为官网展示与对应验证，不增加翻译服务或改变现有功能。首页阅读示例使用固定内容；实际产品界面可点击查看大图。
