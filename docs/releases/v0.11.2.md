# 近译 v0.11.2

本版本针对 Edge 商店上传后的“包中含有压缩文件”校验错误，调整本地中文 PDF 字体的包装和读取方式。商店是否接受安装包、是否通过审核，仍以 Partner Center 的实际结果为准。

## 下载安装

| 浏览器 | 安装包 | 扩展管理页 |
| --- | --- | --- |
| Chrome | [下载 Chrome 安装包](https://github.com/FKstack/near-translate/releases/download/v0.11.2/near-translate-chrome-v0.11.2.zip) | `chrome://extensions` |
| Edge | [下载 Edge 安装包](https://github.com/FKstack/near-translate/releases/download/v0.11.2/near-translate-edge-v0.11.2.zip) | `edge://extensions` |

1. 下载对应 ZIP，完整解压到长期保留的固定文件夹。
2. 打开扩展管理页，开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择直接包含 `manifest.json` 的文件夹，确认版本 **0.11.2**。
4. 固定近译到工具栏，打开普通文章，点击「阅读当前网页」体验本地阅读。

GitHub 自动提供的 Source code 是源码，请下载上表中的安装包。附件 `INSTALL.md` 为安装说明，`SHA256SUMS.txt` 可用于校验 ZIP。商店后台需要直接上传 ZIP，无需解压；手动安装则需先解压。

## 修复内容

- 构建时把本地字体无损解压为普通 TTF，扩展包不再包含 `NearDocumentSans.ttf.gz`。字体仍随扩展提供，中文 PDF 导出无需下载远程字体。
- PDF 导出按需直接读取字体，保留大小限制、取消和完整性检查。
- 发布检查同时核对资源文件名和真实归档文件头，出现嵌套压缩文件时指出具体路径并阻止发布。

普通 TTF 仍由外层 ZIP 压缩；解压后安装目录比 v0.11.1 增加约 4.3 MB。这是磁盘文件大小变化，不代表增加同等的常驻内存。

## 已有用户升级

记录原扩展 ID 和加载路径，备份原程序目录；将新包完整解压到原加载目录，再点击原扩展卡片的「重新加载」。确认版本 **0.11.2** 和扩展 ID，刷新网页、重新打开 PDF 阅读器。

已有 v0.11.1 加密密钥库继续使用原口令。更早版本用户请依照安装指南完成 Key 迁移。模型服务的费用和可用性由所选服务决定。
