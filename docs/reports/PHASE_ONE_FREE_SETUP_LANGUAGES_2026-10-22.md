日期：2026-10-22–23（Asia/Singapore；数字证据使用 UTC 时间）。架构风险：**R2**。本记录依据当前源码，范围为免费服务首用、多语言契约、错误恢复与服务状态观察；0.8.0 已完成的阅读模式继续复用。产品保持不收费，不因竞品的付费功能而建立无限云端模型补贴。

**最终验收：0.9.0 已安装到日常 Edge，全部自动回归与 23 个新标签页真实翻译流程通过。完整条件和证据见第 5、6 节。**

## 1. 用户行为

新用户先看到免费翻译路径，可通过“启用免费翻译”完成所需网页与 DeepL 服务权限授权，无需登录、API Key 或自行理解模型参数。拒绝权限时仍可本地阅读。已有设置的用户保留原引擎、模型、基址、Key 和各服务 profile；主动启用免费翻译也不覆盖旧模型配置。

设置页新增源语言和目标语言，源语言可自动识别或显式指定，目标语言从支持表中选择；修改后点击“保存设置”。网页、阅读模式和 PDF 选文使用同一组已保存语言。Popup 显示当前语言方向并提供设置入口。

“测试免费翻译”是独立的显式动作，只发送固定公开示例句：

> The library opens at nine in the morning.

测试固定为英语到简体中文，不因用户当前目标语言而改变，也不读取当前网页、选区或 PDF。启用权限、打开页面、查看服务状态本身都不执行该测试。测试成功只证明该次短句请求可用，不保证长文速度、全部语种质量或之后不会限流。

限流时展示剩余秒数并禁用相应重试动作，到期只恢复手动按钮；网络/超时可重试，配置/鉴权错误提供设置入口。页面与阅读层可继续未完成部分，并保留已完成内容，不自动重试整篇或自动切换服务。

## 3. 模块职责与数据所有权

| 所有者 | 当前职责与约束 |
| --- | --- |
| `shared/languages` | 单一语言表、源/目标类型、名称、严格请求验证、旧设置默认、文字筛选及学习能力判断；新增语言通过此处贯通，避免各 UI 单独维护语言列表 |
| `platform/settings` | 继续拥有 `settings:v1` 与原保存队列；无已存设置的新用户默认 DeepL，旧用户沿用原引擎；`enableFreeTranslation` 使用同一串行读/合并/写队列，不丢失 profile；语言变化参与连接修订号 |
| 后台组合根 | 从受信任设置统一取得选定语言快照并覆盖网页请求中的语言，随后装配既有 provider；页面不能自行指定凭证、网络目的地或绕过能力限制 |
| `platform/free-translation-check` | 只拥有显式公开样例检测的单个 owner、AbortController、结果 Promise 和 20 秒期限；provider 仍拥有实际服务预算 |
| `platform/service-status` | 当前文档共享一个状态观察器，统一订阅、可见性监听、一个在途 IPC、轮询计时器与 generation；不持有正文或翻译任务 |
| `ui/translation/RecoveryAction` | 纯恢复呈现与本地倒计时；合并错误 `retryAt` 和服务 `cooldownUntil`，不发 IPC、网络请求或自动重试 |
| `reading/mount` / `reading/translation` | 拥有阅读副本、译文 session、缓存与阅读位置；语言或服务变更时取消旧任务、清除旧译文/缓存，原位重新建立待翻译会话，保留阅读位置并等待用户显式翻译 |

内部依赖维持 shared 作为契约、platform 作为浏览器与存储边界；公开样例检测通过构造参数注入 `TranslationProvider` 和 `toError`，不反向导入 core。page/reading 可使用通用恢复 UI，具体服务协议仍位于 provider 与后台装配层。没有新增全局服务定位器或第二套模型设置存储。

### 公开样例检测

`FreeTranslationCheck.run()` 在已有 owner 时直接返回同一个结果 Promise，合并并发点击；只调用固定公开文本的 `en → zh-Hans` 请求。成功需要完整非空文本结果，长度不超过 2,000 字符，并返回测得的耗时；部分 delta 不算完整成功。错误转换由注入的 `toError` 完成。

20 秒超时或显式取消会中止 signal 并给用户终端结果，不自动重试。若 provider 忽略 abort，用户可先收到超时/取消结果，但唯一 owner 继续占用，直到底层异步工作实际退出并完成清理才释放；期间重复点击仍复用原 Promise，避免误以为取消已完成而叠加更多请求。计时器与 abort 监听在实际 finally 中清理。

后台只接受受信任扩展页面的 `enable-free-translation` 和 `test-free-translation`。同扩展 id 是消息前置条件；样例检测还检查当前引擎、启用状态、DeepL 域名权限及连接代次。该测试不接受用户输入的任意文本。

### 文档内共享状态与错误恢复

每个文档的组合根创建一个 `TranslationServiceStatusClient`，同一文档中的页面栏和阅读层共享订阅。存在订阅时以 1 秒间隔轮询本地 `get-translation-status` IPC；隐藏文档不读，恢复可见或显式刷新时可即时检查，已有 IPC 未结束时合并刷新。该轮询没有远程翻译或探活请求。

`get-translation-status` 仅返回引擎、冷却截止时间与检查时间，不返回正文、Key、模型配置或其他页面信息。客户端验证引擎和非负安全整数时间；无效/失败结果不覆盖有效状态，checkedAt 独自变化不重复通知。最后一个订阅退出时取消计时器与可见性监听，dispose 与 generation 阻止迟到结果通知已销毁界面。

页面栏、阅读与划词共用恢复状态计算。每个视图只有一个本地时钟，提示和按钮共用同一个截止时间，避免错误与全局状态分别显示两个计数器。冷却到期不发送任何翻译请求；CONFIG/AUTH 的“打开设置”仍可点击；原文阅读、已完成译文与显示切换不被冷却阻塞。未给安全截止时间的限流只提示稍后手动重试，不编造剩余秒数。

## 4. 兼容性、隐私与未改变的成本边界

- 旧用户的 Key、服务基址、模型、JSON 模式、profile 和非本轮偏好保持原所有者与迁移规则；启用免费翻译通过现有保存队列合并。
- 正常翻译采用当前已保存语言；公开样例固定用独立语言方向，不改变用户配置。后台/请求代次隔离在途旧设置结果。
- 原有 OpenAI 兼容协议、匿名 DeepL 请求路径、请求大小、并发、启动窗口和跨标签 429 冷却不扩大。样例检测也消耗同一个 provider 预算，没有独立绕过限流的通道。
- 本地阅读、设置读取、服务状态 IPC 与倒计时不上传正文；用户显式点击翻译才发送相应文字。图片展示和原网站仍可能有正常网络活动。
- 状态观察不写正文、浏览轨迹或凭证日志；阅读偏好继续只保存七项无正文设置。切换服务/语言时不持久化旧译文以伪装复用。
- 扩展保持免费不等于上游服务无限或永久可用；自备模型服务仍由其账户或本地部署承担成本。此前 DeepL 全文耗时与 429 不稳定没有因本轮 UI 和语言扩展而解决。

## 7. 后续扩展边界

继续扩语种时，先扩单一语言表及能力测试，再核对各 provider 的语言映射、自动识别、文字筛选、方向属性、缓存失效和固定回归样本；不能用新增选项数量代替后端真实支持。新交互继续复用现有保存队列、后台语言快照和 provider 调度，不为每个场景复制凭证存储或请求预算。

本站自动翻译规则、悬停、输入回填、PDF 整文、OCR 和字幕属于后续独立迭代，本记录不将其计入 0.9.0 已完成能力。面向大众的本阶段价值是首用更少步骤、多语言配置贯通和失败后可手动恢复；能否在同条件任务中优于竞品，仍需单独评测。
